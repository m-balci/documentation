Générez un thème Shopify Online Store 2.0 complet et installable à partir d'un prompt. Téléchargez-le en `.zip` et téléchargez-le dans votre boutique Shopify.

<Note>
  Les thèmes Shopify sont disponibles sur les plans Plus et Premium.
</Note>

## Comment ça marche

<Steps>
  <Step title="Créez un projet de thème Shopify">
    Choisissez **Thème Shopify** comme type de sortie et décrivez votre thème.
  </Step>
  <Step title="Construisez et affinez">
    Discutez avec l'IA pour construire et affiner votre thème.
  </Step>
  <Step title="Téléchargez le thème">
    Téléchargez le thème sous forme de fichier `.zip`.
  </Step>
  <Step title="Installez dans Shopify">
    Téléchargez le `.zip` dans votre admin Shopify et publiez-le quand vous êtes prêt.
  </Step>
</Steps>

## Créer un projet de thème Shopify

<Steps>
  <Step title="Choisissez le type de sortie">
    Sur le tableau de bord, ouvrez le sélecteur de sortie à côté du prompt et choisissez **Thème Shopify**.
  </Step>
  <Step title="Choisissez un template (optionnel)">
    Cliquez sur **Personnaliser** pour choisir un template Shopify, ou laissez-le sur **Automatique**.
  </Step>
  <Step title="Décrivez votre thème">
    Saisissez votre prompt et cliquez sur **Démarrer**.
  </Step>
</Steps>

Le type de sortie est défini lors de la création du projet et ne peut pas être changé ultérieurement.

### Templates de départ

Chaque projet Shopify part d'un thème de base. Par défaut, il s'agit de **Skeleton**, le starter minimal officiel de Shopify. Il fournit à l'IA une structure Online Store 2.0 valide sans styles intégrés, afin que le design soit écrit from scratch pour votre prompt.

Si d'autres templates Shopify sont disponibles sur votre plan, choisissez-en un sous **Personnaliser** pour partir de celui-ci. Avec le sélecteur de templates sur **Automatique**, l'IA choisit parmi les templates Shopify disponibles pour vous.

## Prévisualiser votre thème

Les thèmes Shopify ne peuvent pas être prévisualisés dans l'éditeur Webza, car les thèmes Shopify ne s'affichent que dans une boutique Shopify. Après un build, utilisez **Télécharger le thème (.zip)** dans le panneau d'aperçu et installez le thème dans votre boutique pour le voir.

<Tip>
  Téléchargez le thème dans votre boutique sans le publier. Vous pouvez ensuite le prévisualiser depuis **Online Store → Themes** sans changer votre vitrine en direct.
</Tip>

Le panneau n'affiche pas les boutons Annuler, Refaire ni **Historique des révisions**. Les raccourcis clavier fonctionnent toujours :

- Annuler : `Ctrl/Cmd + Z`
- Refaire : `Ctrl/Cmd + Shift + Z` (ou `Ctrl + Y` sur certains systèmes)

## Installer le thème

<Steps>
  <Step title="Téléchargez le thème">
    Dans l'éditeur Webza, cliquez sur **Télécharger le thème (.zip)**.
  </Step>
  <Step title="Téléchargez sur Shopify">
    Dans votre admin Shopify, allez dans **Online Store → Themes → Add theme → Upload zip file**.
  </Step>
  <Step title="Prévisualisez, personnalisez ou publiez">
    Après le téléchargement, prévisualisez le thème, cliquez sur **Personnaliser** pour le modifier davantage dans Shopify, ou cliquez sur **Publier** pour le rendre en direct.
  </Step>
</Steps>

## Ce que les projets de thème ne peuvent pas faire

Un thème est installé dans Shopify, pas hébergé par Webza, donc certaines fonctionnalités de site web ne sont pas disponibles :

- **Publication et domaines personnalisés** : l'onglet **Domains** n'est pas affiché.
- **GitHub et Supabase** : non disponibles pour les thèmes.
- **Mode Design** : le design system choisi lors de la création est appliqué au moment du build.
- **Images générées par l'IA** : disponibles uniquement pour les projets de site web.
- **Analytics** : la carte analytics est masquée. Ajoutez le suivi dans votre boutique Shopify.

Dans l'éditeur, le bouton **Exporter** est remplacé par **Télécharger le thème (.zip)**.

## Changement de plans

Si vous passez de Plus ou Premium à un plan sans thèmes Shopify, vous pouvez toujours télécharger vos thèmes existants, mais les nouveaux builds sur les projets de thème sont bloqués. Passez à nouveau à un plan supérieur pour continuer à les modifier.

## Dupliquer un projet de thème

Un projet de thème Shopify dupliqué conserve le type de sortie Shopify.
