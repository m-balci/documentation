Un template est la structure de départ à partir de laquelle l'IA construit votre projet. Il fournit un ensemble de pages et de composants prêts à l'emploi, adaptés à un type de projet spécifique, afin que l'IA ne parte pas d'une page blanche.

Les templates contrôlent la structure. Les [design systems](/fr/design-systems) contrôlent l'apparence. Webza combine les deux, donc tout template peut s'associer à n'importe quel design system.

## Choisir un template

Choisissez un template dans la popover **Personnaliser** sur la zone de saisie du tableau de bord, avant de démarrer un projet.

- **Automatique** (par défaut) : l'IA choisit le template qui correspond le mieux à votre prompt lorsqu'elle construit le projet.
- **Un template spécifique** : épinglez l'un des templates listés dans le sélecteur pour que l'IA parte de celui-ci.

Les templates Premium sont disponibles sur les plans Plus et Premium. Sur le plan Free, laissez le sélecteur sur **Automatique** et Webza utilise son point de départ par défaut intégré.

## Types de templates

Les templates appartiennent au même type de sortie que votre projet :

- Les templates **Site web**, pour les sites web hébergés (par défaut).
- Les templates **Thème WordPress**, pour les [thèmes WordPress](/fr/themes/wordpress-themes).
- Les templates **Thème Shopify**, pour les [thèmes Shopify Online Store 2.0](/fr/themes/shopify-themes).

Lorsque vous changez le type de sortie à côté de la zone de saisie, le sélecteur de templates n'affiche que les templates de ce type.

<Note>
  Si aucun template spécifique ne correspond à votre projet, Webza revient à un point de départ par défaut intégré pour ce type de sortie, afin que votre build ne soit jamais bloqué par un manque de template.
</Note>

## Animations

Les templates de site web incluent une bibliothèque d'animations de mouvement, afin que votre site puisse aller au-delà des simples effets de survol :

- Entrées échelonnées
- Effets liés au défilement et parallaxe
- Dessin de lignes SVG
- Compteurs de nombres animés
- Transitions fluides d'onglets et de filtres

Demandez-les dans le chat, par exemple : "Animez le hero et faites compter les statistiques vers le haut lorsqu'elles apparaissent à l'écran." Les animations respectent le paramètre de réduction de mouvement de vos visiteurs.

<Tip>
  Les projets créés à partir d'un template plus ancien reçoivent la bibliothèque d'animations automatiquement la première fois que l'IA en a besoin.
</Tip>
