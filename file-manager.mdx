Open **File Manager** from the sidebar under Projects. You can upload files such as images and documents, preview images and PDFs inline, delete files, and view your storage usage.

## Upload and manage files

From File Manager, upload the files you need for your projects. Preview images and PDFs directly in the interface. Delete files you no longer need. Your storage usage is shown so you can track how much space you are using.

Storage and file size limits depend on your plan and apply per user account, not per project.

## Attach files in chat

You can also attach files directly in project chat. Use the upload button or type **@** to mention files already uploaded to the project. You can attach up to 10 files on the first prompt. The AI receives their public URLs and can use them in images, backgrounds, and download links.

Vision-capable models can see attached images (JPG, PNG, WebP, GIF, up to 4 per message).

## Storage in project settings

Project files are also visible in project **Settings → Storage**. See [Settings](/settings) for more about managing project storage.

## AI-generated images

AI-generated images are saved in the project under `public/images/generated/`.
