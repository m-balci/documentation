デザインシステムは、サイトの視覚的アイデンティティです。デザイントークン（カラー、タイポグラフィ、スペーシング、半径、シャドウ）、名前付きアクセントパレットのセット、Webフォント、およびAIに見た目の適用方法を指示するプレイブックがバンドルされています。

[テンプレート](/ja/templates)は構造を制御します。サイトにどのページとコンポーネントがあるかを決定します。デザインシステムは見た目を制御します。Webzaは両者を組み合わせるため、どのデザインシステムもどのテンプレートとでもペアリングでき、同じテンプレートが多様な見た目を持つことができます。

<Info>
  デザインシステムはすべてのプランで利用可能です。自動選択、手動選択、およびデザインモードは、Free、Plus、Premiumのいずれのプランでも同じように動作します。
</Info>

## 仕組み

Webzaがプロジェクトを構築する際、テンプレートから始めてデザインシステムを上に重ねます。

1. テンプレートがページ構造とコンポーネントを提供します。
2. デザインシステムのベーストークン、選択したアクセントパレット、およびWebフォントが適用されます。
3. 一部のデザインシステムには特定のコンポーネントの独自バージョンが含まれており、テンプレートのコンポーネントを置き換えたり洗練させたりします。
4. AIはデザインシステムのプレイブックに従い、生成されたコードを調整して見た目に合わせます。例えば、ハードコードされたカラーをアクティブなトークンとアクセントに従うように置き換えます。

各プレイブックはまた、サイト全体に一貫したモーションスタイルを設定するため、セクション間でアニメーションが統一感を持ちます。

オーバーレイは予測可能です。異なるデザインシステムやアクセントを選んでも、サイトの構造は変わらずに見た目が変わります。

## Substrate（デフォルト）

SubstrateはWebzaのデフォルトデザインシステムです。温かみのあるニュートラルなプレミアムハウススタイルで、UIおよび本文テキストに**Geist**、編集用途のアクセントにセリフ体の**Newsreader**をペアリングしています。コーナー半径は10pxで、柔らかく重なり合ったシャドウを使用します。

Substrateには6つのアクセントパレットがあります。

| アクセント | 説明 |
| --- | --- |
| indigo | デフォルトのアクセント |
| terracotta | 温かみのある大地色のアクセント |
| blue | クールでクラシックなアクセント |
| emerald | グリーンのアクセント |
| ruby | 大胆な赤のアクセント |
| mono | ニュートラルなモノクロームのアクセント |

## プレミアムデザインシステム

Substrateに加えて、Webzaは10のプレミアムデザインシステムを提供しています。それぞれが独自のタイポグラフィ、カラー、シャドウ、個性を持つ完全な見た目です。

| デザインシステム | 個性 |
| --- | --- |
| Aperture | シャープでクールなアーキテクチャルSaaS。正確で確信に満ちています。 |
| Atrium | 信頼できるエンタープライズSaaS。落ち着いた、信頼性のある、ダッシュボードグレード。 |
| Bloom | 遊び心にあふれ、楽しい。太く丸みを帯びた形状に、明るいキャンディカラーのアクセント。 |
| Botanica | 温かみのあるオーガニックな編集系ウェルネス。落ち着いたプレミアム感。 |
| Carbon | 洗練された開発者ツール。ダークファーストでテクニカル、ターミナルグリーン。 |
| Halcyon | 穏やかで軽やかな夢のようなパステル。無重力で静謐。 |
| Lumen | 鮮やかなモダンフィンテックグロー。発光、グラデーション、ガラスモーフィック。 |
| Monolith | 大胆なブルータリストスイスエディトリアル。ラウドでグラフィック、ハイコントラスト。 |
| Noir | ダークラグジュアリーでシネマティック。高級感があり、抑制されたメタリックアクセント。 |
| Sandstone | 温かみのあるミニマルな編集系。文学的なミニマリズムに魂がある。 |

プレミアムデザインシステムは、Substrateがあるすべての場所に表示されます。**カスタマイズ**のデザインシステムピッカー、**自動**選択、およびエディターのデザインモードです。新しいデザインシステムは随時追加されます。

<Tip>
  多くのデザインシステムにはスタイルガイドのプレビューが含まれています。タイポグラフィ、カラー、ボタン、コンポーネントを表示するページです。デザインシステムピッカーまたはエディターのデザインパネルから開き、適用前に見た目を確認できます。
</Tip>

## デザインシステムを選択する

デザインシステムとアクセントは、3つの方法のいずれかで選択されます。

### 自動（デフォルト）

プロジェクトを作成する際、**カスタマイズ**ポップオーバー内のデザインシステムピッカーは**自動**に設定されています。最初のビルド時に、AIがプロンプトに最も適合するデザインシステムとアクセントを選択し、その選択をプロジェクトに保存します。

### 手動

**自動**の代わりに、**カスタマイズ**ポップオーバーで特定のデザインシステムを選びます。また、そのアクセントパレットの1つを選ぶこともでき、デフォルトのアクセントのままにすることもできます。その後、プロジェクトのすべてのビルドでその見た目が使用されます。

### エディターでテーマを変更する

ビルド済みのWebサイトプロジェクトのデザインシステムまたはアクセントは、エディターからいつでも切り替えることができます。

<Steps>
  <Step title="デザインパネルを開く">
    エディターでデザインモードに切り替えます。**デザイン**パネルがプレビューの横に開きます。
  </Step>
  <Step title="デザインシステムとアクセントを選択する">
    新しいデザインシステムを選び、必要に応じてアクセントパレットも選びます。見た目を比較したい場合は、先にスタイルガイドのプレビューを開いてください。
  </Step>
  <Step title="AIに適用を依頼する">
    Webzaが新しいトークンとアクセントを適用し、サイトを再構築します。プレビューが再読み込みされ、AIはハードコードされたカラーを調整して、サイト全体が新しい見た目に合うようにします。
  </Step>
</Steps>

テーマの変更は、チャットリクエストと同様にクレジットを消費します。他のビルドが実行中の間は、テーマの変更を適用できません。

<Note>
  デザインモードはWebサイトプロジェクトでのみ利用可能です。[WordPress](/ja/themes/wordpress-themes)および[Shopify](/ja/themes/shopify-themes)テーマプロジェクトでは非表示になります。これらのプロジェクトでも作成時に選択したデザインシステムは使用されますが、エディターから切り替えることはできません。
</Note>

## テーマ変更を元に戻す

テーマの変更は、元に戻す/やり直すの1ステップとしてカウントされ、変更履歴にチェックポイントが作成されます。後からプレビューから復元できます。詳細は[プレビュー](/ja/preview)をご覧ください。
