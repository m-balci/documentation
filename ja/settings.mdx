Webzaの**設定**エリアは2つの部分からなります。エディタ内のプロジェクト設定と、サイドバーのアカウント設定です。作成物とアカウントの動作を設定するために使用します。

## プロジェクト設定

エディタで**設定**タブを開きます。表示されるタブはプランとプロジェクトタイプによって異なります。

### 一般

プロジェクトとそのオンラインでの表示方法を形作る基本設定を行います。

| フィールド | 機能 |
| --- | --- |
| **プロジェクト名** | プロジェクトリストの内部ラベル。 |
| **プロジェクトの説明** | 目的を思い出すための内部メモ。 |
| **公開タイトル** | タイトルタグとソーシャルシェアタイトル。 |
| **公開説明** | メタディスクリプションとソーシャルシェアテキスト。 |
| **可視性** | Public（検索エンジンがインデックス可能）またはprivate（noindex）。 |
| **シェア画像** | `og:image`と`twitter:image`に使用されるソーシャルプレビュー画像。以下を参照。 |
| **分析ID** | プランに分析が含まれている場合のトラッキングID。以下を参照。 |
| **GitHubリポジトリリンク** | GitHubが有効な場合の接続されたリポジトリへのリンク。 |

#### シェア画像

最大2 MBのJPG、PNG、またはWebP画像をアップロードします。推奨サイズは1200×630ピクセルです。Webzaはこれをビルド時に`og:image`と`twitter:image`に書き込みます。

<Tip>
  プロジェクトを広く共有する前にシェア画像を設定してください。ソーシャルプラットフォームは最初のスクレイプをキャッシュし、後で更新する必要がある場合はキャッシュ更新ツールを提供するものもあります。
</Tip>

複製されたプロジェクトはシェア画像をコピーしません。新しいプロジェクトで再度アップロードする必要があります。

#### 分析

プランに分析が含まれている場合、**設定 → 一般**にカードが表示され、以下を追加できます。

- **Google Tag Manager container ID**（形式 `GTM-XXXXXXX`）
- **Google tag ID**（形式 `G-…` または `AW-…`）
- **Meta Pixel ID**（8〜20桁）

フィールドを空白のままにすると、そのトラッカーが無効になります。これらは公開サイトが提供されるときに注入されます。エディタのプレビューやコードエクスポートには表示されません。変更は次のリクエストですぐに有効になり、再構築は不要です。AIはこれらのタグを削除できません。

<Note>
  その他のサービス（Hotjar、Clarity、LinkedIn、TikTok、カスタムスクリプト）の場合は、GTMコンテナを追加し、GTM内ですべてを設定してください。
</Note>

このカードはWordPressおよびShopifyテーマプロジェクトでは非表示です。トラッキングはWordPressサイトまたはShopifyストアに直接追加してください。

### ドメイン

プロジェクトがWeb上でどのように到達されるかを管理します。

- **サブドメイン**: 公開されたすべてのサイトは`*.webza.app`サブドメインを取得します。
- **カスタムドメイン**: **Project → Settings → Domains → Custom Domain**で独自のドメインを追加し、必要なDNSレコードを追加して確認します。

このタブはWordPressテーマプロジェクトでは表示されません。詳細は[カスタムドメイン](/ja/custom-domains)ページをご覧ください。

### ナレッジ

最大500文字のカスタム指示を追加します。これらはすべてのビルド時にAIに送信されます。ブランドボイス、対象言語、避けるべきライブラリ、命名規則など、繰り返し使う固定ルールにこのフィールドを使用します。

<Warning>
  短く保ってください。ナレッジテキストはすべてのビルドで課金されます。1回限りのリクエストは[プロジェクトチャット](/ja/project-chat)に属し、ここではありません。
</Warning>

### データベース

自分のSupabase接続のいずれかをプロジェクトにアタッチします。今すぐアタッチしたり、後で別の接続に切り替えたり、いつでもデタッチしたりできます。アタッチと切り替えには、プランのデータベース機能が必要です。ダウングレード後など、デタッチは常に許可されています。

接続がアタッチされている間は、現在のプランが新しいアタッチをサポートしていなくても、データベースタブは表示されたままです。

### ストレージ

このタブには、プロジェクトファイルと、生成されたアプリがWebzaにコールバックするために使用するAPIトークンが表示されます。ファイルストレージのないプランでは、タブは**API**と表示され、トークンのみが表示されます。

### GitHubリポジトリ

ソースを自動的にプッシュするリポジトリを接続します。

- **新しいプライベートリポジトリを作成**: Webzaが作成します。
- **自分の空のリポジトリをアタッチ**: 既存の空のリポジトリをリンクします。

いつでも別のリポジトリに切り替えたり、切断したりできます。**自動プッシュ**をオンにすると、各ビルド後にソースをプッシュします。

## アカウント設定

サイドバーの下部にある**設定**をクリックして、アカウントパネルを開きます。3つのセクションがあります。Account、AI Settings、Privacyです。

### Account

名前とメールアドレスを更新したり、パスワードを変更したりできます。プロフィールは[https://webza.ai/profile](https://webza.ai/profile)でも管理できます。

### AI Settings

このセクションは、独自のAPIキーを使用するPlusおよびPremiumプランで利用できます。

- **プロバイダー**: プロバイダーを選択するか、Webzaクレジットを消費するために**システムデフォルトを使用**のままにします。
- **モデル**: プロバイダーを選択した後に表示されます。
- **APIキー**: 暗号化されて保存され、マスク表示されます。いつでもキーを置き換えたり削除したりできます。キーが保存されると**設定済み**バッジが表示されます。
- **テスト**: 稲妻ボタンをクリックして、キーが機能するか確認します。選択したプロバイダーでは、選択したモデルも確認されます。

独自のキーでのビルドはWebzaによって計測されますが、クレジットからは差し引かれません。AIプロバイダーに請求されます。**システムデフォルトを使用**に戻すと、保存されたキーは保持され、クレジットの消費に戻ります。

#### チャットサウンド

すべてのプランで利用できます。AIが作業している間の通知サウンドスタイルを選択します。**ミニマル**、**遊び心**、**レトロ**、**Sci-Fi**、またはサウンドをオフにします。

### Privacy

- **Cookie設定**: どのCookieを受け入れるかを管理します。
- **データをダウンロード**: アカウントに関して保持されているすべてのエクスポートをリクエストします。これは利用できない場合があります。
- **アカウントを削除**: 削除をリクエストします。削除前に猶予期間があります。セルフサービス削除がオフの場合は、サポートに連絡するよう指示されます。
