ダッシュボードはWebzaでの出発点です。新規プロジェクトの開始、既存プロジェクトの開く、クレジット残高の確認、請求、サポート、設定などのアカウントツールへのアクセスができます。

## 新規プロジェクトを開始する

プロンプトボックスは、ダッシュボードの中央、<strong>何を構築しましょうか？</strong>という挨拶の下にあります。作成したいものを説明し、**開始**を選択してプロジェクトを作成し、そのチャットを開きます。詳細な手順については[クイックスタート](/ja/introduction/getting-started)をご覧ください。

### プロンプトボックス

アイデアをテキストフィールドに入力します。簡潔にしても詳細にしても構いません。例えば`a portfolio website for a photographer`や、各ページとセクションの詳細な説明でも構いません。機能、デザインの好み、要件をより具体的に説明すればするほど、最初の結果は良くなります。ボックスには以下も含まれます。

- **出力タイプ**: プロンプトの横のセレクター（デフォルトは**Webサイト**）で、Webzaが作成するものを選択します。WordPressまたはShopifyのテーマを含むプラン（PlusおよびPremium）の場合に表示されます。
  - **Webサイト**: Webzaがホストするサイト。
  - **WordPressテーマ**: インストール可能なWordPressブロックテーマ。ブラウザ内のWordPress Playgroundでプレビューし、テーマ`.zip`としてエクスポートします。
  - **Shopifyテーマ**: インストール可能なShopify Online Store 2.0テーマ。テーマ`.zip`をダウンロードし、Shopifyストアにインストールします。
- **カスタマイズ**: 出発点のすべてのオプションを含むポップオーバーを開きます。[プロジェクトのカスタマイズ](#プロジェクトのカスタマイズ)をご覧ください。
- **マイク**: ブラウザベースの音声入力を使って、手を使わずにプロジェクトを説明します。
- **添付**: 最初のプロンプトに最大10個のファイル（ロゴ、写真、PDFなど）を添付できます。ファイル添付はファイルストレージを含むプランで利用でき、各ファイルはプロジェクト作成前にプランのファイルサイズ、タイプ、ストレージ制限に対してチェックされます。
- **開始**: プロジェクトを作成し、チャットを開きます。

<Note>
  最初のプロンプトは、後続のチャットメッセージと同様に最大10,000文字まで入力できます。制限に近づくとカウンターが表示されます。
</Note>

### プロジェクトのカスタマイズ

**カスタマイズ**ポップオーバーには、出発点のすべてのセレクターが含まれます。

- **テンプレート**: プロジェクトが開始する構造、つまりどのページとコンポーネントが存在するか。**自動**のままにすると、AIが構築時に選択します。または特定のテンプレートを選択します。PremiumテンプレートはPlusおよびPremiumプランで利用できます。[テンプレート](/ja/templates)をご覧ください。
- **デザインシステム**: サイトの視覚的アイデンティティ。カラートークン、アクセントパレット、フォントです。**自動**のままにすると、最初の構築時にプロンプトに最適なものをAIが選択します。または特定のデザインシステムを選択して外観を固定します。Substrateと10のPremiumデザインシステムがすべてのプランで利用できます。[デザインシステム](/ja/design-systems)をご覧ください。
- **アクセント**: 特定のデザインシステムを選択した場合、その名前付きアクセントパレットのいずれかを選択するか、デフォルトのアクセントを維持します。
- **データベース**: 自分のSupabase接続のいずれかをアタッチして、アプリにデータベースを持たせます。[データベース](#プロジェクト)をご覧ください。
- **連携**: GitHubリポジトリを接続します。

テンプレートとデザインシステムは独立しているため、どのデザインシステムもどのテンプレートとも組み合わせられます。WordPressおよびShopifyテーマの場合、データベースとGitHubのオプションは適用されません。

## サイドバーとナビゲーション

左側のサイドバーから、アカウントのすべてにアクセスできます。

- **作成**: ダッシュボードのプロンプトボックスに戻り、新規プロジェクトを開始します。

### プロジェクト

**プロジェクト**セクションは、見出しの横の矢印で折りたたむことができます。

- **すべてのプロジェクト**: プロジェクトの閲覧、お気に入り登録、複製、削除ができます。[プロジェクトの管理](#プロジェクトの管理)をご覧ください。
- **ファイルマネージャー**: 画像やドキュメントなどのファイルをアップロードし、画像やPDFをインラインでプレビューし、ファイルを削除し、ストレージ使用量を確認します。ストレージとファイルサイズの制限はプランによって異なり、アカウント全体に適用され、各プロジェクトではありません。[ファイルマネージャー](/ja/file-manager)をご覧ください。
- **データベース**: 自分のSupabase接続を追加します。有効になっている機能によっては、Supabaseにサインインして接続する（**Supabaseで接続**）、プロジェクトスコープのアクセストークンを貼り付ける、または接続文字列を使って手動で接続する方法があります。接続を使用するアプリは、リレーショナルPostgresテーブル、認証、ストレージ、行レベルセキュリティ（RLS）を取得します。[Supabase](/ja/integrations/supabase)をご覧ください。
- **GitHub**: プロジェクトにGitHubリポジトリを接続します。新しいプライベートリポジトリを作成するか、すでに所有している空のリポジトリをアタッチします。自動プッシュがオンになっている場合、Webzaは各構築後に生成されたソースコードをリポジトリにプッシュします。後からプロジェクトの設定でリポジトリの接続、切り替え、切断ができます。[GitHub](/ja/integrations/github)をご覧ください。
- **APIキー**: 読み取り専用のWebza REST API用のパーソナルAPIキーを作成します。各キーは作成時に一度だけ表示され、30日、90日、または365日後に期限切れになり、最大10個のキーを持つことができます。APIアクセスはPlusおよびPremiumプランで利用できます。[パーソナルAPI](/ja/integrations/personal-api)をご覧ください。
- **APIドキュメント**: curl、JavaScript、PHP、Pythonのコピー＆ペーストサンプルとインタラクティブテスター付きで、すべてのAPIエンドポイントを一覧表示します。APIはアカウント、クレジット、サブスクリプション、プロジェクト、通知、請求書を公開します。
- **請求**: プラン、クレジット、使用量、取引履歴の表示、またはサブスクリプションの解約ができます。[請求書と請求](/ja/invoices-and-billing)および[サブスクリプションの変更または解約](/ja/change-or-cancel-your-subscription)をご覧ください。
- **サポート**: サポートチケットを開封し、フォローします。[サポートチケット](/ja/help/support-tickets)をご覧ください。
- **設定**: アカウント、AI設定、プライバシーを管理します。[設定](/ja/settings)をご覧ください。

<Warning>
  APIは読み取り専用です。プロジェクトの作成、構築のトリガー、請求の変更はできません。APIキーは秘密にしてください。キーは取り消すか期限切れになるまで、アカウントデータへのアクセスを許可します。
</Warning>

### ツアーを再開

ダッシュボードを初めて開いたとき、まず必要なインターフェースの部分を指し示す短いガイドツアーが開始する場合があります。ステップごとに進めるか、閉じることができます。サイドバーの下部にある**ツアーを再開**を選択して、いつでも再生できます。プロジェクト内では、エディタツールバーの**再構築**の横にある円形矢印ボタンでエディタツアーを再生します。

## プロジェクトの管理

**すべてのプロジェクト**には、プロジェクトがカウント付きの3つのタブで表示されます。

- **すべて**: 作業中のすべてのもの。
- **お気に入り**: 行からスターを付けてピン留めしたプロジェクト。スター付けは利便性のためのフィルタのみで、プロジェクトは変更されません。
- **ゴミ箱**: 削除されたプロジェクト。**復元**を選択して戻すか、**完全に削除**して今すぐ削除します。

各プロジェクト行には、**複製**を含むアクションメニューもあり、`<元の名前> (Copy)`という名前の新しいプロジェクトを作成します。詳細は[プロジェクトを探す](/ja/find-a-project)をご覧ください。

<Warning>
  ゴミ箱のプロジェクトは、保持期間後にファイル、プレビュー、スナップショットとともに完全に削除されます。完全な削除は元に戻せません。{/* TODO: Confirm Webza's trash retention period (script default is 90 days). */}
</Warning>

## ヘルプを取得する

サイドバーで**サポート**を選択してチケットを確認し、**新規チケット**を選択して開きます。件名を追加し、問題を説明し、エラーのスクリーンショットなどのファイルを添付します。返信はメールで届き、チケットにスレッド化されます。

チケットは、サポートチームが作業中の間は**オープン**、あなたの返信を待っている間は**保留中**、完了すると**クローズ**の状態になります。クローズしたチケットに返信すると再開されるため、重複を作成する必要はありません。すべてのメンバーがチケットを開け、PlusおよびPremiumには優先サポートが含まれます。

<Tip>
  チケットはあなたとWebzaチームのみが読めるため、アカウント固有の詳細を記載するのに適しています。明示的に求められない限り、パスワードやAPIキーを貼り付けないでください。
</Tip>
