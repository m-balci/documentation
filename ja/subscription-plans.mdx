## プランの比較

各プランは、異なるタイプのユーザー向けに設計されています。

| プラン | 価格 | 最適な用途 |
| --- | --- | --- |
| **Free** | \$0.00/月 | 無料でWebzaを試す |
| **Plus**（最も人気） | \$19.99/月 | 1つのプロジェクトを作成して公開する |
| **Premium** | \$49.99/月 | 無制限のプロジェクトでフル機能を使用する |

### プロジェクトとAIクレジット

| 機能 | Free | Plus | Premium |
| --- | --- | --- | --- |
| プロジェクト | 1 | 1 | 無制限 |
| AIクレジット | 200万（1回限り） | 毎月700万 | 毎月2,000万 |
| 独自のAPIキーを使用 | — | ✓ | ✓ |
| 高度なAIアシスタンス | — | ✓ | ✓ |
| Webエージェント | ✓ | ✓ | ✓ |

クレジットの計算方法、トップアップ、ボーナスクレジットについては、[クレジットと使用量](/ja/credits-and-usage)をご覧ください。

### 公開とドメイン

| 機能 | Free | Plus | Premium |
| --- | --- | --- | --- |
| カスタムサブドメイン | 1 | 無制限 | 無制限 |
| カスタムドメイン | — | 1 | 3 |
| 非公開プロジェクトの表示設定 | ✓ | ✓ | ✓ |
| ホワイトラベル | — | ✓ | ✓ |
| アナリティクス | ✓ | ✓ | ✓ |

所有しているドメインを接続するには、[カスタムドメイン](/ja/custom-domains)をご覧ください。

  <Step title="Freeから始める">

  </Step>
</Steps>

## FAQ

<AccordionGroup>
  <Accordion title="プランをアップグレード、ダウングレード、または解約するにはどうすればよいですか？">
    アップグレードまたはダウングレードするには、メニューの**サポート**ページからチケットを開いてください。解約するには、**請求**ページに移動し、**サブスクリプションを解約**を選択します。プランの特典は、現在の請求期間の終了まで有効です。詳細は[サブスクリプションの変更または解約](/ja/change-or-cancel-your-subscription)をご覧ください。
  </Accordion>

  <Accordion title="Freeプランのクレジットは毎月更新されますか？">
    いいえ。Freeプランには、1回限りの付与として200万のAIクレジットが含まれます。PlusおよびPremiumには、毎月新しいクレジットが配分されます。
  </Accordion>

  <Accordion title="Freeプランで独自のドメインを接続できますか？">
    いいえ。カスタムドメインはPlus（1ドメイン）およびPremium（3ドメイン）で利用できます。Freeでは、カスタムの`webza.ai`サブドメインに公開できます。
  </Accordion>

  <Accordion title="いくつのプロジェクトを作成できますか？">
    FreeおよびPlusには1つのプロジェクトが含まれます。Premiumには無制限のプロジェクトが含まれます。
  </Accordion>

  <Accordion title="請求書はどこで確認できますか？">
    [請求書と請求](/ja/invoices-and-billing)をご覧ください。
  </Accordion>

  <Accordion title="返金は受けられますか？">
    返金は[Webza利用規約](https://webza.ai/terms)に従います。
  </Accordion>
</AccordionGroup>
