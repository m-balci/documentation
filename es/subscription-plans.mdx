## Comparar planes

Cada plan está diseñado para un tipo de usuario diferente.

| Plan | Precio | Ideal para |
| --- | --- | --- |
| **Free** | \$0.00/mes | Explorar Webza sin costo |
| **Plus** (el más popular) | \$19.99/mes | Construir y lanzar un único proyecto |
| **Premium** | \$49.99/mes | Proyectos ilimitados con toda la potencia |

### Proyectos y créditos de IA

| Función | Free | Plus | Premium |
| --- | --- | --- | --- |
| Proyectos | 1 | 1 | Ilimitados |
| Créditos de IA | 2M (una sola vez) | 7M por mes | 20M por mes |
| Usar tu propia clave de API | — | ✓ | ✓ |
| Asistencia avanzada de IA | — | ✓ | ✓ |
| Web Agent | ✓ | ✓ | ✓ |

Para saber cómo se cuentan los créditos, las recargas y los créditos de bonificación, consulta [Créditos y uso](/es/credits-and-usage).

### Publicación y dominios

| Función | Free | Plus | Premium |
| --- | --- | --- | --- |
| Subdominios personalizados | 1 | Ilimitados | Ilimitados |
| Dominios personalizados | — | 1 | 3 |
| Visibilidad privada del proyecto | ✓ | ✓ | ✓ |
| White Label | — | ✓ | ✓ |
| Analytics | ✓ | ✓ | ✓ |

Para conectar un dominio que ya posees, consulta [Dominios personalizados](/es/custom-domains).

## Elegir un plan

<Steps>
  <Step title="Empieza con Free">
    Toda cuenta nueva comienza en el plan Free. [Crea una cuenta](/es/introduction/create-an-account) para construir tu primer proyecto sin costo.
  </Step>
  <Step title="Actualiza cuando necesites más">
    Elige **Plus** para conectar un dominio personalizado, exportar código, usar el acceso a API, partir de plantillas premium y obtener soporte prioritario para un proyecto. Elige **Premium** para proyectos ilimitados y hasta 3 dominios personalizados.
  </Step>
  <Step title="Cambia tu plan en cualquier momento">
    Para actualizar o reducir, abre un ticket desde la página **Soporte**. Consulta [Cambiar o cancelar tu suscripción](/es/change-or-cancel-your-subscription).
  </Step>
</Steps>

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Cómo actualizo, reduzco o cancelo mi plan?">
    Para actualizar o reducir, abre un ticket desde la página **Soporte** en el menú. Para cancelar, ve a la página **Facturación** y selecciona **Cancelar suscripción**. Los beneficios de tu plan permanecen activos hasta el final del período de facturación actual. Consulta [Cambiar o cancelar tu suscripción](/es/change-or-cancel-your-subscription).
  </Accordion>

  <Accordion title="¿Los créditos del plan Free se renuevan cada mes?">
    No. El plan Free incluye 2M de créditos de IA como una asignación única. Plus y Premium incluyen una nueva asignación de créditos cada mes.
  </Accordion>

  <Accordion title="¿Puedo conectar mi propio dominio en el plan Free?">
    No. Los dominios personalizados están disponibles en Plus (1 dominio) y Premium (3 dominios). En Free, puedes publicar en un subdominio personalizado de `webza.ai`.
  </Accordion>

  <Accordion title="¿Cuántos proyectos puedo crear?">
    Free y Plus incluyen 1 proyecto. Premium incluye proyectos ilimitados.
  </Accordion>

  <Accordion title="¿Dónde encuentro mis facturas?">
    Consulta [Facturas y pagos](/es/invoices-and-billing).
  </Accordion>

  <Accordion title="¿Puedo obtener un reembolso?">
    Los reembolsos se rigen por los [Términos de servicio de Webza](https://webza.ai/terms).
  </Accordion>
</AccordionGroup>
