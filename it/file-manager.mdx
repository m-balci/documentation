Apri **Gestione file** dalla sidebar sotto **Progetti**. Puoi caricare file come immagini e documenti, visualizzare in anteprima immagini e PDF inline, eliminare file e visualizzare il tuo utilizzo dello spazio di archiviazione.

## Caricare e gestire i file

Da Gestione file, carica i file necessari per i tuoi progetti. Visualizza in anteprima immagini e PDF direttamente nell'interfaccia. Elimina i file che non ti servono più. Il tuo utilizzo dello spazio di archiviazione viene mostrato così puoi tenere traccia di quanto spazio stai usando.

I limiti di archiviazione e dimensione dei file dipendono dal tuo piano e si applicano per account utente, non per progetto.

## Allegare file in chat

Puoi anche allegare file direttamente nella chat del progetto. Usa il pulsante di caricamento o digita **@** per menzionare file già caricati nel progetto. Puoi allegare fino a 10 file nel primo prompt. L'AI riceve i loro URL pubblici e può utilizzarli in immagini, sfondi e link di download.

I modelli con capacità visiva possono vedere le immagini allegate (JPG, PNG, WebP, GIF, fino a 4 per messaggio).

## Archiviazione nelle impostazioni del progetto

I file del progetto sono visibili anche nelle **Impostazioni → Archiviazione** del progetto. Vedi [Impostazioni](/it/settings) per maggiori informazioni sulla gestione dell'archiviazione del progetto.

## Immagini generate dall'AI

Le immagini generate dall'AI vengono salvate nel progetto sotto `public/images/generated/`.
