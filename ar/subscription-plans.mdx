## مقارنة الخطط

كل خطة مصممة لنوع مختلف من المستخدمين.

| الخطة | السعر | الأنسب لـ |
| --- | --- | --- |
| **Free** | \$0.00/شهر | استكشاف Webza بدون تكلفة |
| **Plus** (الأكثر شيوعاً) | \$19.99/شهر | بناء وإطلاق مشروع واحد |
| **Premium** | \$49.99/شهر | مشاريع غير محدودة بكامل القوة |

### المشاريع وأرصدة الذكاء الاصطناعي

| الميزة | Free | Plus | Premium |
| --- | --- | --- | --- |
| المشاريع | 1 | 1 | غير محدود |
| أرصدة الذكاء الاصطناعي | 2M (مرة واحدة) | 7M شهرياً | 20M شهرياً |
| استخدام مفتاح API الخاص بك | — | ✓ | ✓ |
| مساعدة ذكاء اصطناعي متقدمة | — | ✓ | ✓ |
| وكيل الويب | ✓ | ✓ | ✓ |

لمعرفة كيفية احتساب الأرصدة، والتعبئة، والأرصدة الإضافية، راجع [الأرصدة والاستخدام](/ar/credits-and-usage).

### النشر والنطاقات

| الميزة | Free | Plus | Premium |
| --- | --- | --- | --- |
| النطاقات الفرعية المخصصة | 1 | غير محدود | غير محدود |
| النطاقات المخصصة | — | 1 | 3 |
| رؤية المشروع الخاص | ✓ | ✓ | ✓ |
| White Label | — | ✓ | ✓ |
| التحليلات | ✓ | ✓ | ✓ |

لربط نطاق تمتلكه، راجع [النطاقات المخصصة](/ar/custom-domains).

### الكود والتكاملات

| الميزة | Free | Plus | Premium |
| --- | --- | --- | --- |
| تكامل قاعدة البيانات | ✓ | ✓ | ✓ |
| تكامل GitHub | ✓ | ✓ | ✓ |
| تصدير الكود | — | ✓ | ✓ |
| الوصول إلى API | — | ✓ | ✓ |
| قوالب WordPress | — | ✓ | ✓ |
| قوالب Shopify | — | ✓ | ✓ |
| القوالب المتميزة | — | ✓ | ✓ |

### الدعم

| الميزة | Free | Plus | Premium |
| --- | --- | --- | --- |
| تذاكر الدعم من صفحة **الدعم** | ✓ | ✓ | ✓ |
| دعم ذو أولوية | — | ✓ | ✓ |

## اختيار خطة

<Steps>
  <Step title="ابدأ بالمجانية">
    كل حساب جديد يبدأ بالخطة المجانية. [أنشئ حساباً](/ar/introduction/create-an-account) لبناء مشروعك الأول بدون تكلفة.
  </Step>
  <Step title="ارفع الخطة عند الحاجة إلى المزيد">
    اختر **Plus** لربط نطاق مخصص، وتصدير الكود، واستخدام الوصول إلى API، والبدء من قوالب متميزة، والحصول على دعم ذي أولوية لمشروع واحد. اختر **Premium** لمشاريع غير محدودة وحتى 3 نطاقات مخصصة.
  </Step>
  <Step title="غيّر خطتك في أي وقت">
    لرفع أو خفض خطتك، افتح تذكرة من صفحة **الدعم**. راجع [تغيير أو إلغاء اشتراكك](/ar/change-or-cancel-your-subscription).
  </Step>
</Steps>

## الأسئلة الشائعة

<AccordionGroup>
  <Accordion title="كيف أرفع أو أخفّض أو ألغي خطتي؟">
    لرفع أو خفض الخطة، افتح تذكرة من صفحة **الدعم** في القائمة. للإلغاء، انتقل إلى صفحة **الفوترة** واختر **إلغاء الاشتراك**. تبقى مزايا خطتك نشطة حتى نهاية فترة الفوترة الحالية. راجع [تغيير أو إلغاء اشتراكك](/ar/change-or-cancel-your-subscription).
  </Accordion>

  <Accordion title="هل تتجدد أرصدة الخطة المجانية كل شهر؟">

  </Accordion>

  <Accordion title="هل يمكنني ربط نطاقي الخاص في الخطة المجانية؟">

  </Accordion>

  <Accordion title="كم عدد المشاريع التي يمكنني إنشاؤها؟">
