محرر الأكواد هو محرر Monaco مدمج يتيح لك عرض وتحرير ملفات المشروع مباشرة. يقدم تمييز بنية الأكواد، والبحث والاستبدال، والحفظ عند الطلب، ومؤشر التغييرات غير المحفوظة حتى تعرف دائماً ما ينتظر الحفظ.

## اللغات المدعومة

يُميّز المحرر بنية الأكواد لأكثر أنواع ملفات الويب شيوعاً:

- JavaScript و TypeScript (`.js`، `.ts`، `.tsx`)
- CSS و HTML
- JSON و Markdown

## البحث والاستبدال

اضغط <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>F</kbd> لفتح صندوق البحث داخل المحرر. يمكنك البحث في الملف الحالي واستبدال التطابقات واحداً تلو الآخر أو كلها دفعة واحدة.

## حفظ تغييراتك

اضغط <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>S</kbd> لحفظ الملف الحالي. تظهر نقطة أو مؤشر تغييرات غير محفوظة بجانب اسم الملف حتى تحفظ. تتحدث المعاينة المباشرة بعد الحفظ.

لا يمكنك حفظ ملف أثناء بناء الذكاء الاصطناعي. يُظهر المحرر رسالة توضح السبب، ويحتفظ بنصك غير المحفوظ لتحفظه بمجرد انتهاء البناء.

## ملفات للقراءة فقط

مجموعة صغيرة من ملفات النظام للقراءة فقط. تُدار من قبل القالب ونظام البناء، وتحرير خاطئ قد يترك المشروع غير قادر على إعادة البناء. عند اختيار أحد هذه الملفات، يُظهر المحرر شارة **للقراءة فقط** مع قفل ويخفي زر **حفظ**.

<AccordionGroup>
  <Accordion title="ملفات للقراءة فقط على مستوى الجذر">
    `index.html`، `package.json`، `package-lock.json`، `vite.config.ts`، `tsconfig.json`، `tsconfig.node.json`، `components.json`، `tailwind.config.ts`، `tailwind.config.js`، `postcss.config.js`، `postcss.config.cjs`
  </Accordion>

  <Accordion title="ملفات مصدر للقراءة فقط">
    `src/main.tsx`، `src/index.css`، `src/vite-env.d.ts`
  </Accordion>

  <Accordion title="ملفات نظام للقراءة فقط">
    `memory.json`، `design-intelligence.json`، `KNOWLEDGE.md`، `template.json`
  </Accordion>
</AccordionGroup>

لا يوجد إعداد لفك قفل هذه الملفات. `index.html` هو فقط القشرة التي تحمّل التطبيق. كل صفحة مرئية ورأس وتذييل ورابط يعيش تحت `src/`، وكل شيء هناك قابل للتحرير باستثناء `main.tsx` و`index.css` و`vite-env.d.ts`.

## مقتطفات التحليلات والتتبع

إذا كنت بحاجة لإضافة Google Tag Manager أو Google tag أو Meta Pixel، استخدم بطاقة **التحليلات** في **الإعدادات → العام** بدلاً من تحرير ترميز head مباشرة. راجع [الإعدادات](/ar/settings).

## تحذيرات مهمة

<Warning>
  التعديلات اليدوية التي تُجرى وأنت داخل سجل المراجعات (بعد التراجع) تُلغى من قبل عملية تراجع أو استعادة تالية. راجع [المعاينة](/ar/preview) للتفاصيل حول سجل المراجعات.
</Warning>

<Info>
  الصور المُنشأة بالذكاء الاصطناعي تُخزّن في `public/images/generated/`. يمكنك الإشارة إليها في أكوادك، لكن لا تنقلها أو تُعيد تسميتها خارج المحادثة وإلا قد يفقدها الذكاء الاصطناعي.
</Info>
