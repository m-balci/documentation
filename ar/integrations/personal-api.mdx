تتضمن خطط Plus و Premium وصولاً إلى API. API الشخصي هو API REST للقراءة فقط يتيح لك الوصول إلى بيانات حساب Webza الخاص بك برمجيًا. لا يمكنك إنشاء مشاريع أو تشغيل عمليات بناء أو تغيير الفوترة عبر API.

## إنشاء مفتاح API

افتح صفحة **مفاتيح API** من الشريط الجانبي.

<Steps>
  <Step title="أنشئ مفتاحًا">
    انقر لإنشاء مفتاح جديد. يُعرض كل مفتاح مرة واحدة فقط عند الإنشاء، لذا انسخه فورًا واحتفظ به بأمان.
  </Step>
  <Step title="عيّن تاريخ انتهاء (اختياري)">
    اختر تاريخ انتهاء 30 أو 90 أو 365 يومًا، أو اتركه بدون انتهاء.
  </Step>
  <Step title="ألغِ عند الحاجة">
    يمكنك إلغاء أي مفتاح في أي وقت. يمكنك امتلاك ما يصل إلى 10 مفاتيح لكل حساب.
  </Step>
</Steps>

<Warning>
  احتفظ بمفاتيحك سرًا. تمنح وصولاً إلى بيانات حسابك حتى يُلغى أو ينتهي.
</Warning>

## المصادقة

أرسل مفتاحك كـ Bearer token في ترويسة `Authorization`:

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" https://webza.ai/api/v1/...
```

## نقاط النهاية والتوثيق

يفتح API الموارد تحت `/api/v1` لحسابك، وأرصادتك، والاشتراك، والمشاريع، والإشعارات، والفواتير.

افتح صفحة **توثيق API** من الشريط الجانبي لرؤية كل نقطة نهاية. يتضمن التوثيق أداة اختبار تفاعلية وعينات جاهزة للنسخ في curl وJavaScript وPHP وPython.
