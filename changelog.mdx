<Update label="October 2026">
  ### New

  - **AI image generation**: The AI can create custom images for website projects. If your plan includes it, a monthly image allowance applies. See [Project chat](/project-chat).
  - **Image understanding**: When the selected model supports images, the AI can now see the images you attach to a prompt or chat message.
  - **Fix for free**: Runs that fail because of the AI or the platform are not charged. You can retry a failed run once for free, and the Usage page marks these runs as not charged. See [Credits and usage](/credits-and-usage).
  - **More ways to connect Supabase**: Connect by signing in with Supabase or with an access token. Manual connections no longer need your secret key. See [Supabase](/integrations/supabase).
  - **Effort setting**: Choose **Auto**, **Low**, **Medium**, or **High** effort for each project in the editor and on the **Create** page. Higher effort can use more credits. Models without an effort control show the setting disabled.
  - **Project names**: New projects get a short AI-generated name. It appears in page titles, theme names, and the project list instead of your prompt.
  - **Publish window shortcuts**: For a live site, the Publish window now offers **Visit**, **Copy link**, and **Unpublish**. See [Publish](/publish).

  ### Improved

  - Website templates now include the Motion animation library, so the AI can build richer animations such as staggered entrances, parallax, and animated counters. See [Templates](/templates).
  - Previews on website projects now build in the background. Rebuild, Undo, Redo, restore, style edits, and design changes return right away with a small **Updating preview** indicator. A message you send meanwhile no longer waits for the preview.
  - **Stop** now restores the site to how it was before your message, and **Redo** brings the partial changes back. The project stays locked until the stopped build has fully finished.
  - Stopped and failed builds now use the credits they spent. Builds that fail because of the platform stay free. See [Credits and usage](/credits-and-usage).
  - In shared projects, the person who sends a message pays for it with their own plan, credits, Web Agent pages, and AI images.
  - Credits for cached input now follow each AI provider's real price.
  - The AI checks your remaining credits before each request, keeps its last answer within what is left, and finishes the step it already paid for. The chat shows a clear notice when you reach your credit limit.
  - When the AI sends an invalid request, it now resends it instead of failing the build. A build that still fails this way is not charged (within the daily free-fix limit) and offers a free fix.
  - A failed preview update now keeps the last working preview. Builds that lost track of their progress are marked as interrupted instead of staying stuck.
  - Long conversations keep the summary of earlier messages when you send new ones.
  - The [code editor](/code-editor) now refuses to save a file while the AI is building, shows a clear message, and keeps your unsaved text.
  - The AI model lists now use the current generation of models, and saved settings move off retired models.
  - Better security: the editor preview runs in a sandbox, and published sites no longer receive your dashboard login, so code in a generated site cannot act as the person viewing it. Owners open private sites, including those on custom domains, with **Visit**.
  - The project token in published sites can only reach files the site itself uploaded, and is hidden from view-only collaborators.
  - Project code exports now include a `.gitignore` file and show a readable message when they fail.
  - More consistent pages across the dashboard: confirmations before deleting, inline field errors, loading states, keyboard access, right-to-left layouts, and translated labels.

  ### Fixed

  - WordPress themes now apply the selected design system's colors and tokens reliably. Dark design systems (Carbon, Lumen, and Noir) now start in dark mode.
  - Shopify themes now get the design system's colors when the template is picked automatically, and untouched starter files no longer show false validation errors.
  - Two builds, or a build and an undo, no longer run on the same project at once.
  - The editor no longer loses your message when a build cannot start. It now explains why and keeps your text.
  - Fixed many editor issues, including silent build failures, edits reported as sent when they failed, and history disappearing mid-session.
  - A manual save made after Undo is no longer discarded by Redo.
  - The AI no longer starts building when it only answered a question on a site that was already built.
  - Subdomain-style [custom domains](/custom-domains) such as `shop.example.com` now need only their own A record and get a certificate for that name.
  - Custom domains entered with `www` (such as `www.example.com`) no longer pass verification without the bare domain record the certificate needs.
  - Publishing validation messages are now translated.
  - WordPress theme downloads now include their `theme.json` font and color settings.
  - The credits indicator no longer breaks the editor toolbar after a session expires.
  - Notifications now show on the **File Manager** and **Project Settings** pages.
</Update>

<Update label="September 2026">
  ### New

  - **Newer AI models**: The model lists now include the latest AI models. If a model you saved is retired, Webza switches you to the closest current model of the same class.
  - **Attach files to your first prompt**: If your plan includes file storage, attach up to 10 files when you create a project.
  - **Design guidance for the AI**: While it builds, the AI now follows focused playbooks on page composition, section layout, motion, safe redesigns, and copy accuracy.
  - **Consistent motion**: Each [design system](/design-systems) now sets one motion style, so animation timing and easing stay consistent across your site.

  ### Improved

  - Your first prompt can now be up to 10,000 characters, the same as follow-up messages.
  - Quality checks now catch dead "#" links in generated sites.
  - Faster page loads across the dashboard.
  - Better screen reader support for toggles, filters, and icon-only buttons.
  - Accounts with no credits left now see a warning that they can't build.

  ### Fixed

  - The AI no longer links to your uploaded files with wrong addresses, which stopped images from loading.
  - Changes to published sites on custom domains now reach visitors right away.
  - Addresses ending in a slash now open the right page on published and preview sites.
  - The Design panel no longer reports a new style as applied when the rebuild behind it failed. The same fix applies to Undo, Redo, and restoring a revision.
  - Question cards in the chat no longer stretch the page or break scrolling.
  - The **Code** tab no longer shows a "Failed to load files" error on a project that has never been built.
</Update>

<Update label="August 2026">
  ### New

  - **Clarifying questions**: The AI can ask you questions during a build. Answer them with tappable choices right in the chat. See [Project chat](/project-chat).
  - **Guided tours**: Step-by-step tours of the dashboard, project creation, the editor, billing, the file manager, databases, GitHub, and Shopify. Replay them anytime with **Restart tour**.
  - **Cookie preferences**: Change your cookie consent choices anytime from the **Cookie preferences** link in the footer.

  ### Improved

  - Faster page loads and a broad accessibility pass: screen readers now announce form errors, loading states, upload results, and search results.
  - The AI now handles long conversations better and no longer says it is summarizing on every message.

  ### Fixed

  - Dark mode now follows Webza's own theme switch instead of your operating system setting.
  - The Revision History panel, including its restore buttons, is no longer cut off on mobile browsers.
  - The builder no longer reports "Build complete" when the AI changed no files.
  - Chat messages no longer go missing when several updates arrive at once.
  - Creating a GitHub repository now shows the real reason when it fails.
  - Build failures now show a single, clear message.
  - A rejected file save in the code editor no longer reports success and loses your edit.
</Update>
