Erstellen Sie Ihre erste Website mit Webza und bringen Sie sie in etwa zehn Minuten live ins Internet. Es gibt nichts zu installieren und nichts zu konfigurieren: Sie beschreiben, was Sie wollen, Webza entwirft und baut sie, und Sie veröffentlichen sie unter einer echten Adresse, die Sie teilen können. In dieser Anleitung erstellen Sie eine Website für **Golden Crust**, eine fiktive Nachbarschaftsbäckerei, mit einer Startseite, einer Speisekarte mit Preisen und einem Bestellformular. Ersetzen Sie Ihre eigene Idee in jedem Schritt; der Prozess bleibt derselbe.

Das Bauen mit Webza verwendet [Credits](/de/credits-and-usage), und der kostenlose Tarif umfasst eine einmalige Gutschrift von 2 Millionen KI-Credits. Unter [Abonnementpläne](/de/subscription-plans) erfahren Sie, was jeder Tarif bietet.

<Steps>
  <Step title="Konto erstellen">
    [Melden Sie sich kostenlos an](https://webza.ai/register?utm_source=webza_docs&utm_medium=content) mit E-Mail, Google oder GitHub. Webza öffnet Ihr Dashboard, bereit zum Bauen. Für Login, Passwort-Reset und Kontoeinstellungen siehe [Konto erstellen](/de/introduction/create-an-account).
  </Step>
  <Step title="Website beschreiben">
    Das Eingabefeld im [Dashboard](/de/introduction/dashboard-overview) ist der Ausgangspunkt für jedes Projekt. Beschreiben Sie die gewünschte Website in einfacher Sprache.

    Probieren Sie diese Eingabeaufforderung aus oder passen Sie sie an Ihre eigene Idee an:

    ```text Prompt wrap
    Erstelle eine Website für Golden Crust, eine Nachbarschaftsbäckerei. Füge einen warmen Hero-Bereich mit einer Überschrift und einem "Online bestellen"-Button hinzu, eine Speisekartenseite mit Sauerteigbrot, Croissants und Zimtschnecken mit Preisen, einen Über-uns-Bereich mit der Geschichte der Bäckerei und ein Bestellformular, in dem Besucher ihren Namen, die gewünschten Artikel und eine Abholzeit eingeben. Verwende realistische Beispielinhalte. Gemütliches, modernes Design. Funktioniert gut auf Mobilgeräten.
    ```

    <Tip>
      Seien Sie spezifisch bezüglich Seiten, Abschnitten und dem gewünschten Gefühl. Je mehr Kontext Sie in der ersten Eingabeaufforderung geben, desto näher kommt die erste Version dem, was Sie sich vorgestellt haben.
    </Tip>

    <Accordion title="Stattdessen eigene Idee verwenden">
      Passen Sie einen dieser Starters an oder schreiben Sie Ihre eigene Eingabeaufforderung von Grund auf. Die Schritte in dieser Anleitung bleiben dieselben.

      ```text Portfolio wrap
      Erstelle eine Portfolio-Website für einen freiberuflichen Fotografen: eine galerie in voller Breite, eine Über-uns-Seite, einen Bereich für Dienstleistungen und Preise und ein Kontaktformular. Minimalistisches, elegantes Design.
      ```

      ```text Lokales Unternehmen wrap
      Erstelle eine Website für eine Zahnarztpraxis: eine Startseite mit Dienstleistungen, einen Team-Bereich mit Fotos, Öffnungszeiten, einen Standort-Bereich und ein Formular für Terminanfragen. Sauberes, vertrauenswürdiges Design.
      ```

      ```text Landing Page wrap
      Erstelle eine Landing Page für eine mobile App, die Menschen hilft, ihre tägliche Wasseraufnahme zu verfolgen: ein Hero mit einem Download-Button, einen Funktions-Bereich, Testimonials und ein FAQ. Frisches, helles Design.
      ```
    </Accordion>
  </Step>
  <Step title="Zuschauen, wie die erste Version entsteht">
    Webza erstellt Ihr Projekt und beginnt mit dem Bauen. Die erste Version dauert einige Minuten.

    Wenn sie fertig ist, arbeiten Sie im [Editor](/de/editor): Der [Projekt-Chat](/de/project-chat), in dem Sie mit Webza sprechen, befindet sich neben der [Vorschau](/de/preview), in der Ihre Website live läuft. Klicken Sie sich durch die Vorschau, öffnen Sie das Menü und scrollen Sie durch die Abschnitte.
  </Step>
  <Step title="Eine Änderung vornehmen">
    Bitten Sie im Projekt-Chat um jeweils eine Änderung und prüfen Sie die Vorschau nach jeder einzelnen. Zum Beispiel:

    ```text Prompt wrap
    Füge oberhalb der Speisekarte einen Bereich "Heutige Specials" hinzu, der zwei Artikel mit einer kurzen Beschreibung und einem Preis hervorhebt.
    ```

    Wenn die Website funktioniert, aber nicht so aussieht, wie Sie es sich vorgestellt haben, sagen Sie es in einfachen Worten. Das ist eine völlig legitime Eingabeaufforderung:

    ```text Prompt wrap
    Mach die gesamte Website wärmer und weniger corporate.
    ```

    Sie können auch visuell im [Editor](/de/editor) bearbeiten oder den [Code-Editor](/de/code-editor) für die volle Kontrolle über die Dateien Ihrer Website öffnen. Ihre Änderungen bleiben privat, bis Sie [veröffentlichen](/de/publish).
  </Step>
  <Step title="Prüfen, ob alles funktioniert">
    Bevor Sie veröffentlichen, nehmen Sie sich einen Moment Zeit, um Ihre Website zu testen:

    - Klicken Sie jeden Button und jeden Link an.
    - Füllen Sie das Bestellformular aus, um sicherzustellen, dass jedes Feld funktioniert.
    - Prüfen Sie, wie die Website auf einem Telefon aussieht. Die meisten Besucher werden Ihren Link auf einem Mobilgerät öffnen.

    Wenn etwas nicht stimmt, sagen Sie Webza genau, was falsch ist und wo:

    ```text Prompt wrap
    Auf der Speisekartenseite tut der "Online bestellen"-Button nichts. Er sollte zum Bestellformular scrollen.
    ```
  </Step>
  <Step title="Veröffentlichen">
    Wählen Sie **Veröffentlichen** im Editor, neben den anderen Projektaktionen. Nach einer kurzen Bereitstellung ist Ihre Website live auf einer kostenlosen `webza.ai`-Subdomain (zum Beispiel `golden-crust.webza.ai`), bereit zum Teilen. Unter [Website veröffentlichen](/de/publish) finden Sie Details, und unter [Eigene Domains](/de/custom-domains) erfahren Sie, wie Sie stattdessen Ihre eigene Domain verwenden.

    <Note>
      **Ihre Live-Website ist ein Snapshot.** Änderungen, die Sie nach der Veröffentlichung vornehmen, erscheinen sofort in der Vorschau, aber die Live-Website aktualisiert sich erst, wenn Sie erneut veröffentlichen.
    </Note>
  </Step>
</Steps>

Das ist der gesamte Kreislauf: beschreiben, verfeinern, veröffentlichen. Jede Website, die Sie mit Webza bauen, wie auch immer ambitioniert, ist dieser Kreislauf, der sich wiederholt.
