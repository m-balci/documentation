Generieren Sie ein installierbares WordPress Full Site Editing (FSE) Block Theme aus dem gleichen Chat, den Sie zum Erstellen von Websites verwenden. Sehen Sie es live in Ihrem Browser in der Vorschau an, laden Sie es als `.zip` herunter und installieren Sie es auf jeder WordPress-Website mit Version 6.7 oder neuer.

<Note>
  WordPress Themes sind auf den Plus- und Premium-Plänen verfügbar.
</Note>

## Was Sie erhalten

Ein WordPress Theme-Projekt erzeugt ein Block Theme anstelle einer Website. Das Theme enthält:

- `theme.json` mit den Farben, Fonts und Abständen Ihres Design-Systems
- Block-Templates und Template-Teile
- Patterns
- Styles

Webza prüft bei jedem Build die Struktur und PHP-Syntax des Themes, sodass das heruntergeladene Theme sofort installiert werden kann.

## WordPress Theme-Projekt erstellen

Auf dem Dashboard erscheint neben dem Prompt ein Ausgabewähler:

| Ausgabe | Ergebnis |
| --- | --- |
| **Website** | Der Standard. Eine Website, die Sie auf einer Subdomain oder einer benutzerdefinierten Domain veröffentlichen können. |
| **WordPress-Theme** | Ein installierbares FSE Block Theme. |

Wählen Sie **WordPress-Theme**, geben Sie Ihren Prompt ein und starten Sie das Projekt. Der Ausgabetyp wird bei der Projekterstellung festgelegt und kann später nicht mehr geändert werden.

<Tip>
  Sie können auch von einem WordPress-Template aus starten. Für WordPress erstellte Templates erscheinen neben den Website-Templates.
</Tip>

## Theme in der Vorschau ansehen

Webza zeigt Themes in der WordPress Playground in der Vorschau an: ein echtes WordPress, das in Ihrem Browser läuft, mit Ihrem Theme installiert und aktiviert. Sie benötigen keinen Server oder Hosting, um das Ergebnis zu sehen.

Die Playground hat ihre eigene Neulade-Steuerung. Da sie eine vollständige WordPress-Instanz startet, können der erste Ladevorgang und Vorschau-Updates einen Moment dauern.

<Warning>
  Die Playground ist eine Vorschau, kein Hosting. Alles darin lebt in Ihrem Browser-Tab und ist weg, wenn Sie ihn schließen. Um das Theme zu verwenden, laden Sie die `.zip` herunter und installieren Sie es auf Ihrer WordPress-Website.
</Warning>

## Bearbeiten und iterieren

Rückgängig, Wiederholen und Revisionshistorie funktionieren für Theme-Projekte genauso wie für Websites. Wenn Sie eine Revision wiederherstellen, startet die Playground-Vorschau mit dem wiederhergestellten Theme neu, sodass Sie von diesem Punkt aus weiterbearbeiten können.

## Herunterladen und installieren

<Steps>
  <Step title="Theme herunterladen">
    Öffnen Sie das Projekt im Webza-Editor und klicken Sie auf **Theme herunterladen (.zip)**. Die `.zip` ist nach Ihrem Projekt benannt.
  </Step>
  <Step title="In WordPress hochladen">
    Gehen Sie in Ihrem WordPress-Admin zu **Appearance → Themes → Add New** und klicken Sie auf **Upload Theme**. Wählen Sie die heruntergeladene `.zip`-Datei und klicken Sie auf **Install Now**.
  </Step>
  <Step title="Aktivieren">
    Nach Abschluss der Installation klicken Sie auf **Activate**, um das Theme auf Ihrer Website anzuwenden.
  </Step>
</Steps>

<Tip>
  Bewahren Sie den heruntergeladenen Dateinamen auf. WordPress verwendet den `.zip`-Namen als Ordnernamen des Themes.
</Tip>

### Anforderungen

- **WordPress 6.7 oder neuer.** Ältere Versionen können die Installation ablehnen oder Templates fehlerhaft anzeigen.
- **PHP 7.4 oder neuer** auf Ihrem WordPress-Server.

## Was Theme-Projekte nicht können

Ein Theme ist eine herunterladbare Datei, keine gehostete Website, sodass einige Website-Funktionen nicht verfügbar sind:

- **Veröffentlichung und benutzerdefinierte Domains**: Webza hostet keine Theme-Projekte, daher wird die Registerkarte **Domains** nie angezeigt.
- **GitHub und Supabase**: nicht für Themes verfügbar.
- **Design-Modus**: das bei der Erstellung gewählte Design-System wird in `theme.json` eingebaut.
- **KI-generierte Bilder**: nur für Website-Projekte verfügbar.
- **Analytics**: die Analytics-Karte ist ausgeblendet. Fügen Sie Tracking direkt in Ihrer WordPress-Website hinzu.

Im Editor wird die Schaltfläche **Exportieren** durch **Theme herunterladen (.zip)** ersetzt.

## Planwechsel

Wenn Sie von Plus oder Premium zu einem Plan ohne WordPress Themes wechseln, können Sie Ihre bestehenden Themes weiterhin herunterladen, aber neue Builds auf Theme-Projekten werden blockiert. Upgraden Sie erneut, um sie weiter zu bearbeiten.
