A template is the starting structure the AI builds your project from. It provides a ready-made set of pages and components tailored to a specific type of project, so the AI does not start from a blank page.

Templates control structure. [Design systems](/design-systems) control the look. Webza combines the two, so any template can pair with any design system.

## Choose a template

Pick a template from the **Customize** popover on the dashboard prompt box, before you start a project.

- **Automatic** (default): AI picks the template that best fits your prompt when it builds the project.
- **A specific template**: Pin one of the templates listed in the picker so the AI starts from it.

Premium templates are available on the Plus and Premium plans. On the Free plan, leave the picker on **Automatic** and Webza uses its built-in default starting point.

## Template types

Templates belong to the same output type as your project:

- **Website** templates, for hosted websites (the default).
- **WordPress Theme** templates, for [WordPress block themes](/themes/wordpress-themes).
- **Shopify Theme** templates, for [Shopify Online Store 2.0 themes](/themes/shopify-themes).

When you change the output type next to the prompt box, the template picker shows only the templates for that type.

<Note>
  If no specific template fits your project, Webza falls back to a built-in default starting point for that output type, so your build never fails for lack of a template.
</Note>

## Animations

Website templates include a motion animation library, so your site can go beyond simple hover effects:

- Staggered entrances
- Scroll-linked and parallax effects
- SVG line drawing
- Animated number counters
- Smooth tab and filter transitions

Ask for them in the chat, for example: "Animate the hero and make the stats count up when they scroll into view." Animations respect your visitors' reduced-motion setting.

<Tip>
  Projects created from an older template get the animation library added automatically the first time the AI needs it.
</Tip>
