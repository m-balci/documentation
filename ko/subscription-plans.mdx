## 요금제 비교

각 요금제는 다른 유형의 사용자를 위해 설계되었습니다.

| 요금제 | 가격 | 가장 적합한 경우 |
| --- | --- | --- |
| **Free** | \$0.00/월 | 비용 없이 Webza를 탐색할 때 |
| **Plus** (가장 인기) | \$19.99/월 | 단일 프로젝트를 빌드하고 출시할 때 |
| **Premium** | \$49.99/월 | 무제한 프로젝트를 최대한 활용할 때 |

### 프로젝트 및 AI 크레딧

| 기능 | Free | Plus | Premium |
| --- | --- | --- | --- |
| 프로젝트 | 1 | 1 | 무제한 |
| AI 크레딧 | 2M (1회) | 월 7M | 월 20M |
| 자체 API 키 사용 | — | ✓ | ✓ |
| 고급 AI 지원 | — | ✓ | ✓ |
| 웹 에이전트 | ✓ | ✓ | ✓ |

크레딧 계산 방법, 추가 충전, 보너스 크레딧에 대해서는 [크레딧 및 사용량](/ko/credits-and-usage)을 참조하세요.

### 게시 및 도메인

| 기능 | Free | Plus | Premium |
| --- | --- | --- | --- |
| 사용자 지정 하위 도메인 | 1 | 무제한 | 무제한 |
| 사용자 지정 도메인 | — | 1 | 3 |
| 비공개 프로젝트 가시성 | ✓ | ✓ | ✓ |
| 화이트 라벨 | — | ✓ | ✓ |
| 분석 | ✓ | ✓ | ✓ |

소유한 도메인을 연결하는 방법은 [사용자 지정 도메인](/ko/custom-domains)을 참조하세요.

  <Step title="더 필요할 때 업그레이드하기">

  </Step>
</Steps>
