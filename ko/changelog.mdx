<Update label="2026년 10월">
  ### 새로운 기능

  - **AI 이미지 생성**: AI가 웹사이트 프로젝트를 위한 사용자 지정 이미지를 생성할 수 있습니다. 요금제에 포함된 경우 월간 이미지 할당량이 적용됩니다. [프로젝트 채팅](/ko/project-chat)을 참조하세요.
  - **이미지 이해**: 선택한 모델이 이미지를 지원할 때, AI는 이제 프롬프트나 채팅 메시지에 첨부한 이미지를 볼 수 있습니다.
  - **무료로 수정**: AI나 플랫폼 문제로 실패한 실행은 요금이 부과되지 않습니다. 실패한 실행을 한 번 무료로 재시도할 수 있으며, 사용량 페이지는 이러한 실행을 미청구로 표시합니다. [크레딧 및 사용량](/ko/credits-and-usage)을 참조하세요.
  - **Supabase 연결 방법 확대**: Supabase로 로그인하거나 액세스 토큰으로 연결할 수 있습니다. 수동 연결은 더 이상 비밀 키가 필요하지 않습니다. [Supabase](/ko/integrations/supabase)를 참조하세요.

  ### 개선 사항

  - 웹사이트 템플릿에 이제 Motion 애니메이션 라이브러리가 포함되어 AI가 더 풍부한 애니메이션(예: 지연 등장, 패럴랙스, 애니메이션 카운터)을 빌드할 수 있습니다. [템플릿](/ko/templates)을 참조하세요.

  ### 수정 사항

  - WordPress 테마가 이제 선택한 디자인 시스템의 색상과 토큰을 안정적으로 적용합니다. 다크 디자인 시스템(Carbon, Lumen, Noir)은 이제 다크 모드로 시작합니다.
  - Shopify 테마는 이제 템플릿이 자동으로 선택될 때 디자인 시스템의 색상을 받으며, 수정되지 않은 시작 파일이 더 이상 잘못된 유효성 검사 오류를 표시하지 않습니다.
</Update>

<Update label="2026년 9월">
  ### 새로운 기능

  - **최신 AI 모델**: 모델 목록에 이제 최신 AI 모델이 포함됩니다. 저장한 모델이 단종되면 Webza는 동일한 클래스의 가장 가까운 현재 모델로 전환합니다.
  - **첫 프롬프트에 파일 첨부**: 요금제에 파일 저장소가 포함된 경우 프로젝트를 생성할 때 최대 10개의 파일을 첨부할 수 있습니다.
  - **AI를 위한 디자인 가이드**: 빌드 중 AI는 이제 페이지 구성, 섹션 레이아웃, 모션, 안전한 재디자인, 복사 정확성에 대한 집중적인 플레이북을 따릅니다.
  - **일관된 모션**: 각 [디자인 시스템](/ko/design-systems)이 이제 하나의 모션 스타일을 설정하므로, 애니메이션 타이밍과 이징이 사이트 전체에서 일관되게 유지됩니다.

  ### 개선 사항

  - 첫 프롬프트는 이제 후속 메시지와 동일하게 최대 10,000자까지 입력할 수 있습니다.
  - 품질 검사가 이제 생성된 사이트의 죽은 "#" 링크를 포착합니다.
  - 대시보드 전체에서 더 빠른 페이지 로드.
  - 토글, 필터, 아이콘 전용 버튼에 대한 더 나은 스크린 리더 지원.
  - 크레딧이 남아 있지 않은 계정은 이제 빌드할 수 없다는 경고를 표시합니다.

  ### 수정 사항

  - AI가 더 이상 업로드된 파일을 잘못된 주소로 링크하여 이미지가 로드되지 않는 문제를 해결했습니다.
  - 사용자 지정 도메인의 게시된 사이트 변경 사항이 이제 방문자에게 즉시 반영됩니다.
  - 슬래시로 끝나는 주소가 이제 게시 및 미리보기 사이트에서 올바른 페이지를 엽니다.
  - 디자인 패널이 더 이상 뒤의 빌드가 실패했을 때 새 스타일이 적용되었다고 보고하지 않습니다. 실행 취소, 다시 실행, 버전 복원에도 동일한 수정이 적용됩니다.
  - 채팅의 질문 카드가 더 이상 페이지를 늘리거나 스크롤을 망가뜨리지 않습니다.
  - **코드** 탭이 빌드된 적 없는 프로젝트에서 "Failed to load files" 오류를 더 이상 표시하지 않습니다.
</Update>

<Update label="2026년 8월">
  ### 새로운 기능

  - **확인 질문**: AI가 빌드 중 질문을 할 수 있습니다. 채팅에서 탭할 수 있는 선택지로 답변하세요. [프로젝트 채팅](/ko/project-chat)을 참조하세요.
  - **안내 투어**: 대시보드, 프로젝트 생성, 편집기, 결제, 파일 관리자, 데이터베이스, GitHub, Shopify에 대한 단계별 투어. **투어 다시 시작**으로 언제든 다시 재생할 수 있습니다.
  - **쿠키 기본 설정**: 하단의 **쿠키 기본 설정** 링크에서 언제든 쿠키 동의 선택을 변경할 수 있습니다.

  ### 개선 사항

  - 더 빠른 페이지 로드 및 광범위한 접근성 개선: 스크린 리더가 이제 양식 오류, 로딩 상태, 업로드 결과, 검색 결과를 알려줍니다.
  - AI가 이제 긴 대화를 더 잘 처리하며, 모든 메시지에서 요약 중이라고 말하지 않습니다.

  ### 수정 사항

  - 다크 모드가 이제 운영 체제 설정 대신 Webza 자체의 테마 스위치를 따릅니다.
  - 모바일 브라우저에서 수정 기록 패널과 복원 버튼이 더 이상 잘리지 않습니다.
  - AI가 파일을 변경하지 않았을 때 빌더가 더 이상 "Build complete"를 보고하지 않습니다.
  - 여러 업데이트가 동시에 도착할 때 채팅 메시지가 더 이상 사라지지 않습니다.
  - GitHub 저장소 생성이 실패할 때 이제 실제 이유를 표시합니다.
  - 빌드 실패가 이제 단일하고 명확한 메시지를 표시합니다.
  - 코드 편집기에서 거부된 파일 저장이 더 이상 성공으로 보고되고 편집 내용을 잃지 않습니다.
</Update>
