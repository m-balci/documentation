Webza의 **설정** 영역은 두 부분으로 구성됩니다: 편집기 내부의 프로젝트 설정과 사이드바의 계정 설정입니다. 이를 사용하여 만드는 것과 계정의 동작 방식을 구성하세요.

## 프로젝트 설정

편집기에서 **설정** 탭을 엽니다. 표시되는 탭은 요금제와 프로젝트 유형에 따라 다릅니다.

### 일반

프로젝트를 형성하고 온라인에서 어떻게 표시되는지에 대한 기본 사항을 설정합니다.

| 필드 | 기능 |
| --- | --- |
| **프로젝트 이름** | 프로젝트 목록의 내부 레이블입니다. |
| **프로젝트 설명** | 목적을 기억하는 데 도움이 되는 내부 메모입니다. |
| **게시된 제목** | Title 태그와 소셜 공유 제목입니다. |
| **게시된 설명** | Meta 설명과 소셜 공유 텍스트입니다. |
| **공개 설정** | Public(검색 엔진이 색인할 수 있음) 또는 private(noindex). |
| **공유 이미지** | `og:image`와 `twitter:image`에 사용되는 소셜 미리보기 이미지입니다. 아래를 참조하세요. |
| **분석 ID** | 요금제에 분석이 포함된 경우 추적 ID입니다. 아래를 참조하세요. |
| **GitHub 저장소 링크** | GitHub이 활성화된 경우 연결된 저장소 링크입니다. |

#### 공유 이미지

최대 2MB의 JPG, PNG, WebP 이미지를 업로드하세요. 권장 크기는 1200x630 픽셀입니다. Webza는 빌드 시 이를 `og:image`와 `twitter:image`에 기록합니다.

<Tip>
  프로젝트를 널리 공유하기 전에 공유 이미지를 설정하세요. 소셜 플랫폼은 첫 스크랩을 캐시하며, 나중에 업데이트해야 할 경우 캐시 새로고침 도구를 제공하는 플랫폼도 있습니다.
</Tip>

복제된 프로젝트는 공유 이미지를 복사하지 않습니다. 새 프로젝트에서 다시 업로드해야 합니다.

#### 분석

요금제에 분석이 포함된 경우, **설정 → 일반**에 다음을 추가할 수 있는 카드가 나타납니다:

- **Google Tag Manager container ID** (형식 `GTM-XXXXXXX`)
- **Google tag ID** (형식 `G-…` 또는 `AW-…`)
- **Meta Pixel ID** (8~20자리 숫자)

해당 추적기를 비활성화하려면 필드를 비워 두세요. 이들은 게시된 사이트가 제공될 때 주입됩니다. 편집기 미리보기나 코드 내보내기에는 표시되지 않습니다. 변경 사항은 재빌드 없이 다음 요청 시 적용됩니다. AI는 이 태그를 제거할 수 없습니다.

<Note>
  다른 서비스(Hotjar, Clarity, LinkedIn, TikTok, 커스텀 스크립트)의 경우 GTM 컨테이너를 추가하고 GTM 내부에서 모든 것을 구성하세요.
</Note>

이 카드는 WordPress 및 Shopify 테마 프로젝트에는 숨겨져 있습니다. WordPress 사이트나 Shopify 스토어에서 직접 추적을 추가하세요.

### 도메인

프로젝트가 웹에서 어떻게 접근되는지 관리합니다.

- **하위 도메인**: 모든 게시된 사이트는 `*.webza.app` 하위 도메인을 받습니다.
- **커스텀 도메인**: 자신의 도메인을 **프로젝트 → 설정 → 도메인 → 커스텀 도메인**에 추가한 다음 필요한 DNS 레코드를 추가하고 인증합니다.

이 탭은 WordPress 테마 프로젝트에는 절대 표시되지 않습니다. 자세한 내용은 [커스텀 도메인](/ko/custom-domains) 페이지를 참조하세요.

### 지식

최대 500자의 커스텀 지시사항을 추가하세요. 이는 모든 빌드 시 AI에 전송됩니다. 반복해서 말하게 되는 지속적인 규칙에 이 필드를 사용하세요: 브랜드 보이스, 대상 언어, 피해야 할 라이브러리, 또는 명명 규칙.

<Warning>
  짧게 유지하세요. 지식 텍스트는 모든 빌드 시 비용이 발생합니다. 일회성 요청은 [프로젝트 채팅](/ko/project-chat)에 속합니다.
</Warning>

### 데이터베이스

Supabase 연결 중 하나를 프로젝트에 연결합니다. 지금 연결을 연결하거나, 나중에 다른 연결로 전환하거나, 언제든지 분리할 수 있습니다. 연결 및 전환은 요금제의 데이터베이스 기능이 필요합니다. 분리는 항상 허용되며, 예를 들어 다운그레이드 후에도 가능합니다.

연결이 연결된 동안에는 현재 요금제가 새 연결을 더 이상 지원하지 않더라도 데이터베이스 탭이 계속 표시됩니다.

### 저장소

이 탭은 프로젝트 파일과 생성된 앱이 Webza에 콜백하는 데 사용하는 API 토큰을 보여줍니다. 파일 저장소가 없는 요금제에서는 탭이 **API**로 레이블되고 토큰만 표시합니다.

### GitHub 저장소

소스를 자동으로 푸시할 저장소를 연결합니다.

- **새 비공개 저장소 만들기**: Webza가 대신 생성합니다.
- **소유한 빈 저장소 연결**: 기존의 빈 저장소를 연결합니다.

언제든지 다른 저장소로 전환하거나 연결을 해제할 수 있습니다. **자동 푸시**를 켜면 매 빌드 후 소스를 푸시합니다.

## 계정 설정

사이드바 하단의 **설정**을 클릭하여 계정 패널을 엽니다. 세 개의 섹션이 있습니다: 계정, AI 설정, 개인정보.

### 계정

이름과 이메일을 업데이트하거나 비밀번호를 변경합니다. 프로필은 [https://webza.ai/profile](https://webza.ai/profile)에서도 관리할 수 있습니다.

### AI 설정

이 섹션은 자신의 API 키를 사용할 때 Plus 및 Premium 요금제에서 사용할 수 있습니다.

- **제공자**: 제공자를 선택하거나 **시스템 기본값 사용**으로 두어 Webza 크레딧을 소비합니다.
- **모델**: 제공자를 선택한 후 표시됩니다.
- **API 키**: 암호화되어 저장되고 마스킹되어 표시됩니다. 언제든지 키를 교체하거나 제거할 수 있습니다. 키가 저장되면 **구성됨** 배지가 나타납니다.
- **테스트**: 번개 볼트 버튼을 클릭하여 키가 작동하는지 확인합니다. 선택된 제공자의 경우 선택된 모델도 확인합니다.

자신의 키로 빌드하면 Webza가 측정하지만 크레딧에서 차감되지 않습니다. AI 제공자에게 비용이 청구됩니다. **시스템 기본값 사용**으로 돌아가면 저장된 키는 유지되고 크레딧 소비로 돌아갑니다.

#### 채팅 소리

모든 요금제에서 사용 가능합니다. AI가 작업하는 동안 알림 소리 스타일을 선택하세요: **미니멀**, **장난스러운**, **레트로**, **SF**, 또는 소리를 끕니다.

### 개인정보

- **쿠키 환경설정**: 수락할 쿠키를 관리합니다.
- **데이터 다운로드**: 계정에 대해 보관된 모든 것의 내보내기를 요청합니다. 이 기능은 사용 불가능할 수 있습니다.
- **계정 삭제**: 삭제를 요청합니다. 제거 전 유예 기간이 있습니다. 셀프 서비스 삭제가 꺼져 있으면 지원팀에 문의하라는 안내가 표시됩니다.
