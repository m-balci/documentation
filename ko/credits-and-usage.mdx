빌드 크레딧은 Webza의 모든 AI 생성을 지원합니다. 각 요금제에는 설정된 할당량이 포함되어 있으며, 월 중에 소진되면 추가 팩을 구매할 수 있습니다.

## 크레딧 작동 방식

크레딧은 AI 토큰 사용량을 기준으로 소모됩니다. 모든 생성, 편집, 빌드 호출마다 소량의 토큰이 소모되며, 실시간으로 잔액에서 차감됩니다.

요금제에 따라 월간 할당량이 결정됩니다.

| 요금제 | 월간 할당량 | 결제 |
| --- | --- | --- |
| Free | 2,000,000 크레딧 (1회) | 구독 없음 |
| Plus | 월 7,000,000 크레딧 | \$19.99/월 |
| Premium | 월 20,000,000 크레딧 | \$49.99/월 |

## 잔액 확인하기

남은 크레딧은 대시보드 상단 표시줄에 표시됩니다. 예: **20,000,000 / 20,000,000 크레딧**.

채팅 헤더에도 크레딧 표시기가 나타납니다.

- 잔액의 20% 이상이 남아 있을 때 **기본 색상**.
- 잔액이 5%에서 20% 사이일 때 **노란색**. 빠른 충전을 위해 **크레딧 구매** 링크가 표시됩니다.
- 잔액이 5% 이하일 때 **빨간색**.
- 자체 API 키로 빌드할 때 **"자체 API 키 사용 중"**.

## 추가 크레딧 구매하기

다음 결제 주기 전에 크레딧이 소진되면, **결제** → **사용량**을 열고 **크레딧 구매**를 클릭하세요. 구독에 사용하는 것과 동일한 결제 수단으로 일회용 크레딧 팩을 구매할 수 있습니다. 결제가 완료되면 즉시 잔액에 추가됩니다.

크레딧 팩은 자동 갱신되지 않으며, 요금제의 월간 할당량도 변경하지 않습니다. 팩 크기와 가격은 요금제에 따라 다를 수 있습니다.

## 자체 API 키 사용하기

Plus 및 Premium 요금제에서는 자신의 AI 공급업체 API 키를 추가할 수 있습니다. 자체 키로 빌드할 때 사용량은 Webza에서 여전히 측정되지만, 요금제 크레딧에서 차감되지 않습니다. 공급업체에게 직접 결제합니다.

설정하려면 [설정](/ko/settings) → **AI 설정**으로 이동하여 API 키를 붙여넣으세요.

## 크레딧 소모 시점

크레딧은 다음 상황에서 소모됩니다.

- 디자인 재테마
- 인스펙터의 **모두 저장** 작업
- 모든 AI 빌드 또는 생성 실행

질문을 하거나 AI 응답을 기다리는 동안에는 크레딧이 **소모되지 않습니다**. 실제 빌드 실행에만 비용이 청구됩니다.

## 무료로 수정

AI 오류나 플랫폼 문제로 실행이 실패한 경우, 해당 실행에 대해 요금이 부과되지 않습니다. 취소한 실행이나 크레딧 부족으로 중단된 실행은 여전히 요금이 부과됩니다.

요금이 부과되지 않는 실행은 **결제** → **사용량**에 짧은 이유와 함께 **미청구**로 표시됩니다. 이러한 미청구 실행은 사용된 크레딧에 포함되지 않습니다.

실행이 실패하면 **무료로 수정**을 클릭하여 24시간 이내에 한 번 무료로 재시도할 수 있습니다. 무료 재시도에는 일일 한도가 있습니다(기본값은 24시간당 5회).

## 사용량 통계

**결제** → **사용량**을 열어 크레딧 소비 내역을 자세히 확인하세요.

- 프로젝트별 사용량
- AI 모델별 사용량
- 미청구 실행 및 사유

이를 통해 어떤 프로젝트나 모델이 가장 많은 크레딧을 사용하는지 파악할 수 있습니다.

## AI 이미지
