사이드바(**프로젝트** 아래)에서 **모든 프로젝트**를 열어 작업 중인 모든 프로젝트, 상태, 계속할 위치를 확인하세요. 이 화면에도 **새 프로젝트** 버튼이 있습니다.

## 프로젝트 탭

프로젝트는 세 개의 탭에 각각 카운트와 함께 정리됩니다:

| 탭 | 표시 내용 |
| --- | --- |
| **전체** | 작업 중인 모든 프로젝트 |
| **즐겨찾기** | 행에서 별표를 눌러 여기에 고정한 프로젝트(이것은 순전히 필터이며 프로젝트를 변경하지 않습니다) |
| **휴지통** | 복구 기간 동안 보관되는 삭제된 프로젝트 |

## 프로젝트 즐겨찾기에 추가

프로젝트 행의 별표 아이콘을 클릭하여 **즐겨찾기** 탭에 고정하세요. 이것은 필터일 뿐입니다. 프로젝트 설정, 공개 설정, 동작을 변경하지 않습니다.

## 휴지통 및 복구

삭제된 프로젝트는 **휴지통** 탭으로 이동합니다. 각 행에는 **복원** 또는 **영구 삭제**가 제공됩니다.

<Warning>
  휴지통은 자동으로 비워집니다. 휴지통의 프로젝트는 보관 기간(기본 90일) 후 파일, 미리보기, 스냅샷과 함께 영구 제거됩니다. 수동이든 자동이든 영구 삭제는 되돌릴 수 없습니다.
</Warning>

프로젝트를 삭제하면 하위 도메인과 커스텀 도메인이 해제되어 재사용할 수 있습니다.

## 프로젝트 복제

프로젝트 행의 작업 메뉴를 열고 **복제**를 선택하여 "original (Copy)"라는 이름의 복사본을 만듭니다.

### 복사되는 것

- 이름과 설명
- 원본 프롬프트
- 템플릿과 출력 유형(웹사이트, WordPress 테마, Shopify 테마)
- 전체 대화 기록과 커스텀 지시사항
- 디자인 시스템과 강조색
- 게시된 제목, 설명, 공개/비공개 공개 설정

### 복사되지 않는 것

복제본은 새로운 게시되지 않은 프로젝트로 시작합니다:

- 하위 도메인 또는 커스텀 도메인 없음
- 공유 이미지 없음
- 빌드 기록 또는 저장소 사용량 없음
- 썸네일 없음
- 분석 ID 없음
- 새로운 API 토큰
- 원본의 Supabase 또는 GitHub 연결 없음

복제본은 라이브 사이트의 클론이 아닌 새로운 시작입니다. 원본 도메인에 응답하지 않습니다. 별도로 게시하고 연결을 다시 연결해야 합니다. 이것은 하위 도메인이 하나의 프로젝트에만 속하고, API 토큰이나 저장소를 공유하면 한 프로젝트가 다른 프로젝트의 파일을 덮어쓸 수 있기 때문입니다.

## 프로젝트 제한

- **Free** 및 **Plus** 요금제에는 1개의 프로젝트가 포함됩니다.
- **Premium**에는 무제한 프로젝트가 포함됩니다.
