디자인 시스템은 사이트의 시각적 정체성입니다. 디자인 토큰(색상, 타이포그래피, 간격, 모서리 반경, 그림자), 명명된 강조 팔레트 세트, 웹 폰트, 그리고 AI가 외형을 적용하는 방법을 알려주는 플레이북을 하나로 묶습니다.

[템플릿](/ko/templates)은 구조를 담당합니다: 사이트에 어떤 페이지와 컴포넌트가 있는지. 디자인 시스템은 외형을 담당합니다. Webza는 둘을 결합하므로, 어떤 디자인 시스템이든 어떤 템플릿이든 함께 사용할 수 있고, 같은 템플릿도 다양한 외형을 가질 수 있습니다.

<Info>
  디자인 시스템은 모든 요금제에서 사용할 수 있습니다. 자동 선택, 수동 선택, 디자인 모드는 Free, Plus, Premium에서 모두 동일하게 작동합니다.
</Info>

## 작동 방식

Webza가 프로젝트를 구축할 때, 템플릿부터 시작하고 그 위에 디자인 시스템을 덧씌웁니다.

1. 템플릿이 페이지 구조와 컴포넌트를 제공합니다.
2. 디자인 시스템의 기본 토큰, 선택한 강조 팔레트, 웹 폰트가 적용됩니다.
3. 일부 디자인 시스템은 특정 컴포넌트의 자체 버전을 포함하여 템플릿의 컴포넌트를 대체하거나 개선합니다.
4. AI는 디자인 시스템의 플레이북을 따르며 외형에 맞게 생성된 코드를 조정합니다. 예를 들어, 활성 토큰과 강조를 따르도록 하드코딩된 색상을 교체합니다.

각 플레이북은 또한 전체 사이트에 대해 하나의 일관된 모션 스타일을 설정하므로, 섹션 간 애니메이션이 동일하게 느껴집니다.

오버레이는 예측 가능합니다. 다른 디자인 시스템이나 강조를 선택하면 사이트 구조를 변경하지 않고 외형만 바뀝니다.

## Substrate (기본값)

Substrate는 Webza의 기본 디자인 시스템입니다. 따뜻하고 중성적이며 프리미엄스러운 하우스 스타일로, UI와 본문 텍스트에는 **Geist**를, 에디토리얼 강조에는 세리프체 **Newsreader**를 사용합니다. 모서리 반경은 10px이며 부드럽고 겹쳐진 그림자를 사용합니다.

Substrate에는 여섯 가지 강조 팔레트가 있습니다.

| 강조 | 설명 |
| --- | --- |
| indigo | 기본 강조 |
| terracotta | 따뜻하고 흙빛 강조 |
| blue | 차갑고 클래식한 강조 |
| emerald | 녹색 강조 |
| ruby | 강렬한 빨간색 강조 |
| mono | 중성적인 모노크롬 강조 |

## 프리미엄 디자인 시스템

Substrate 외에도 Webza는 열 개의 프리미엄 디자인 시스템을 제공합니다. 각각은 고유한 타이포그래피, 색상, 그림자, 개성을 가진 완전한 외형입니다.

| 디자인 시스템 | 개성 |
| --- | --- |
| Aperture | 깔끔하고 차가운 건축적 SaaS. 정확하고 자신감 넘칩니다. |
| Atrium | 신뢰할 수 있는 엔터프라이즈 SaaS. 차분하고 신뢰감 있으며 대시보드급입니다. |
| Bloom | 장난기 많고 즐거운. 두툼하고 둥근 형태에 발랄한 캔디 강조가 특징입니다. |
| Botanica | 따뜻하고 유기적이며 에디토리얼 웰니스. 차분하고 프리미엄스럽습니다. |
| Carbon | 세련된 개발자 도구. 다크 퍼스트, 기술적, 터미널 그린입니다. |
| Halcyon | 평화롭고 청량하며 몽환적인 파스텔. 무중력하고 고요합니다. |
| Lumen | 생동감 있는 현대 핀테크 글로우. 빛나고 그라데이션, 글래스모픽합니다. |
| Monolith | 대담한 브루탈리스트 스위스 에디토리얼. 강렬하고 그래픽, 고대비입니다. |
| Noir | 어두운 럭셔리와 시네마틱. 고급스럽고 절제되며 메탈릭 강조가 특징입니다. |
| Sandstone | 따뜻하고 미니멀하며 에디토리얼. 영혼이 담긴 문학적 미니멀리즘입니다. |

프리미엄 디자인 시스템은 Substrate가 있는 모든 곳에 나타납니다: **사용자 지정**의 디자인 시스템 선택기, **자동** 선택, 에디터의 디자인 모드. 새로운 디자인 시스템은 지속적으로 추가됩니다.

<Tip>
  많은 디자인 시스템은 스타일가이드 미리보기를 포함합니다: 타이포그래피, 색상, 버튼, 컴포넌트를 보여주는 페이지입니다. 디자인 시스템 선택기나 에디터의 디자인 패널에서 열어, 적용 전에 외형을 확인하세요.
</Tip>

## 디자인 시스템 선택하기

디자인 시스템과 강조는 다음 세 가지 방법 중 하나로 선택됩니다.

### 자동 (기본값)

프로젝트를 생성할 때, **사용자 지정** 팝오버의 디자인 시스템 선택기는 **자동**으로 설정됩니다. 첫 번째 빌드에서 AI가 프롬프트에 가장 잘 맞는 디자인 시스템과 강조를 선택하고, 해당 선택을 프로젝트에 저장합니다.

### 수동

**자동** 대신 **사용자 지정** 팝오버에서 특정 디자인 시스템을 선택하세요. 강조 팔레트 중 하나를 선택하거나 기본 강조를 유지할 수도 있습니다. 이후 프로젝트의 모든 빌드는 해당 외형을 사용합니다.

### 에디터에서 테마 변경하기

빌드된 웹사이트 프로젝트의 디자인 시스템이나 강조는 언제든지 에디터에서 변경할 수 있습니다.

<Steps>
  <Step title="디자인 패널 열기">
    에디터에서 디자인 모드로 전환합니다. **디자인** 패널이 미리보기 옆에 열립니다.
  </Step>
  <Step title="디자인 시스템과 강조 선택하기">
    새로운 디자인 시스템을 선택하고, 원한다면 강조 팔레트도 선택하세요. 외형을 비교하려면 먼저 스타일가이드 미리보기를 열어보세요.
  </Step>
  <Step title="AI에게 적용 요청하기 클릭">
    Webza가 새로운 토큰과 강조를 적용하고 사이트를 재구축합니다. 미리보기가 다시 로드되고, AI는 하드코딩된 색상을 조정하여 전체 사이트가 새로운 외형과 일치하도록 합니다.
  </Step>
</Steps>

테마 변경은 채팅 요청처럼 크레딧을 사용합니다. 다른 빌드가 실행 중일 때는 테마 변경을 적용할 수 없습니다.

<Note>
  디자인 모드는 웹사이트 프로젝트에서만 사용할 수 있습니다. [WordPress](/ko/themes/wordpress-themes) 및 [Shopify](/ko/themes/shopify-themes) 테마 프로젝트에서는 숨겨져 있습니다. 해당 프로젝트들은 생성 시 선택한 디자인 시스템을 계속 사용하지만, 에디터에서 전환할 수는 없습니다.
</Note>

## 테마 변경 되돌리기

테마 변경은 실행 취소 및 다시 실행의 한 단계로 계산되며, 수정 기록에 체크포인트를 생성합니다. 나중에 미리보기에서 되돌릴 수 있습니다. 자세한 내용은 [미리보기](/ko/preview)를 참조하세요.
