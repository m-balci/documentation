프로젝트 채팅은 AI로 제작하는 주요 작업 공간입니다. 원하는 것을 입력하면 AI가 코드를 만들고, 편집하거나, 설명해 줍니다. 새 페이지, 기능, 스타일 변경, 버그 수정, 또는 어떤 것이 어떻게 작동하는지에 대한 설명을 요청할 수 있습니다.

## 메시지 보내기

요청 사항을 입력하고 **Enter**를 누르거나 전송 버튼을 클릭하세요. AI가 메시지를 읽고 작업을 시작합니다.

## 파일 첨부

요금제에 파일 저장소가 포함된 경우, AI에 추가 맥락을 제공하기 위해 파일을 첨부할 수 있습니다.

<Steps>
  <Step title="파일 업로드">
    첨부 버튼을 클릭하고 기기에서 파일을 선택합니다. 업로드된 파일은 프로젝트 파일 트리에 표시됩니다.
  </Step>
  <Step title="기존 파일 언급">
    채팅에 `@`를 입력하면 프로젝트에 이미 있는 파일이 자동 완성됩니다.
  </Step>
</Steps>

첨부된 파일은 공개 URL과 함께 AI에 전달됩니다. AI는 이를 이미지, 배경, 또는 다운로드 링크로 사용할 수 있습니다.

### 이미지 첨부 및 비전

비전 기능이 있는 AI 모델을 사용하면, AI가 첨부된 이미지를 직접 볼 수 있습니다. 지원 형식은 JPG, PNG, WebP, GIF입니다. 메시지당 최대 4개의 이미지를 첨부할 수 있습니다. 큰 이미지는 자동으로 축소됩니다. AI는 이미지가 첨부된 메시지에서 이미지를 봅니다.

텍스트 전용 모델을 사용하면, AI는 파일 이름과 URL만 받습니다.

## 메시지 제한

채팅 메시지는 최대 10,000자까지 입력할 수 있습니다. 요청이 긴 경우, 더 작은 단계로 나누는 것을 고려하세요.

## AI 질문에 답하기

요청이 모호할 때, AI는 추측하는 대신 명확화 질문을 합니다. 질문 카드가 채팅 하단에 최대 5개의 짧고 탭 가능한 답변과 함께 나타납니다. 일부 질문은 여러 선택을 허용합니다. 답변을 다시 탭하면 선택이 취소됩니다. 개방형 질문에는 텍스트 필드가 표시됩니다.

하단의 자유 텍스트 상자를 사용하면 전송 전에 추가 세부 사항을 입력할 수 있습니다. 답변은 일반 채팅 메시지로 게시되고 다음 AI 실행을 시작합니다. **×** 버튼으로 카드를 닫고 일반 답변을 입력할 수도 있습니다. 질문은 기록에서 계속 읽을 수 있습니다.

<Info>
  질문을 하면 해당 실행이 종료됩니다. 카드가 답변을 기다리는 동안 크레딧은 소비되지 않습니다.
</Info>

## 빌드 진행 상황 추적

각 AI 실행은 채팅에 표시되는 단계를 거칩니다:

| 단계 | 발생하는 일 |
| --- | --- |
| Thinking | AI가 요청을 분석하고 변경 사항을 계획합니다. |
| Actions | 파일이 생성되거나 수정됩니다. |
| Messages | AI가 무엇을 했고 왜 했는지 설명합니다. |
| Complete | 실행이 완료되고 결과를 미리볼 수 있습니다. |

## 크레딧 표시기

채팅 헤더에 현재 크레딧 상태가 표시됩니다:

- **기본 색상:** 크레딧의 20% 이상이 남아 있습니다.
- **노란색:** 5%에서 20% 사이가 남아 있으며, **크레딧 구매** 링크가 있습니다.
- **빨간색:** 5% 이하가 남아 있습니다.

무제한 요금제에서는 **무제한 크레딧**이 표시됩니다. 자신의 API 키로 빌드할 때는 **자신의 API 키 사용 중**이 표시됩니다. 자세한 내용은 [크레딧 및 사용량](/ko/credits-and-usage)을 참조하세요.

## 무료로 수정

AI 에이전트나 플랫폼 때문에 실패한 실행은 과금되지 않습니다. 여기에는 에이전트가 반복적인 오류 후 중단된 실행, 최종 빌드 검사가 실패한 실행, 또는 결과물 없이 토큰이 소비된 실행이 포함됩니다. 크레딧이 떨어져 실패한 실행이나 사용자가 취소한 실행은 과금됩니다.

실패한 실행 후 채팅 아래에 **무료로 수정** 버튼이 나타납니다. 클릭하면 AI에게 새 기능을 추가하지 않고 문제를 진단하고 수정하도록 요청합니다. 해당 수정 실행도 무료입니다. 버튼은 고정된 지시사항을 보냅니다. 채팅 상자의 텍스트는 포함되지 않습니다.

<Warning>
  각 실패한 실행은 24시간 이내에 한 번만 무료로 수정할 수 있으며, 최신 실행일 때만 가능합니다.
</Warning>

무료 처리된 실행은 **결제 → 사용량**에 **과금 안 됨**으로 표시됩니다. 사용자당 무료 처리 실행의 일일 한도가 있습니다.

## AI 생성 이미지

요금제에 AI 이미지가 포함된 경우, AI는 스톡 사진이 적합하지 않거나 특정한 것을 요청할 때 웹사이트 프로젝트용 커스텀 이미지를 만들 수 있습니다. 예를 들어 "황혼의 등대 커스텀 히어로 이미지를 생성해 줘"라고 말할 수 있습니다.

생성된 이미지는 `public/images/generated/`에 저장되고 파일 트리에 표시됩니다. 각 이미지는 텍스트 변경보다 조금 더 오래 걸립니다.

월간 허용량은 **사용량** 페이지의 **현재 요금제** 카드에 표시됩니다. 소진되면 다음 달력월까지 AI는 스톡 사진을 사용합니다.

## 커스텀 지시사항

AI가 모든 빌드에서 받는 지시사항을 추가하세요. 프로젝트 **설정 → 지식**으로 이동하여 최대 500자를 입력합니다. 톤, 브랜딩, 코딩 스타일 규칙 등에 유용합니다. 자세한 내용은 [설정](/ko/settings)을 참조하세요.
