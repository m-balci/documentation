코드 편집기는 내장 Monaco 편집기로, 프로젝트 파일을 직접 보고 편집할 수 있습니다. 구문 강조, 검색 및 바꾸기, 요청 시 저장, 저장되지 않은 변경 사항 표시기를 제공하여 항상 무엇이 보류 중인지 알 수 있습니다.

## 지원 언어

편집기는 가장 일반적인 웹 파일 유형에 대한 구문 강조를 제공합니다:

- JavaScript 및 TypeScript (`.js`, `.ts`, `.tsx`)
- CSS 및 HTML
- JSON 및 Markdown

## 검색 및 바꾸기

<kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>F</kbd>를 눌러 편집기 내부의 검색 상자를 엽니다. 현재 파일에서 검색하고 일치 항목을 하나씩 또는 한 번에 모두 바꿀 수 있습니다.

## 변경 사항 저장

<kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>S</kbd>를 눌러 현재 파일을 저장합니다. 저장하기 전까지 파일 이름 옆에 점 또는 저장되지 않은 변경 사항 표시기가 나타납니다. 저장 후 라이브 미리보기가 업데이트됩니다.

## 읽기 전용 파일

소수의 시스템 파일은 읽기 전용입니다. 이들은 템플릿과 빌드 시스템에서 관리하며, 잘못된 편집은 프로젝트를 재빌드할 수 없게 만들 수 있습니다. 이러한 파일 중 하나를 선택하면 편집기는 **읽기 전용** 잠금 배지를 표시하고 **저장** 버튼을 숨깁니다.

<AccordionGroup>
  <Accordion title="루트 수준 읽기 전용 파일">
    `index.html`, `package.json`, `package-lock.json`, `vite.config.ts`, `tsconfig.json`, `tsconfig.node.json`, `components.json`, `tailwind.config.ts`, `tailwind.config.js`, `postcss.config.js`, `postcss.config.cjs`
  </Accordion>

  <Accordion title="소스 읽기 전용 파일">
    `src/main.tsx`, `src/index.css`, `src/vite-env.d.ts`
  </Accordion>

  <Accordion title="시스템 읽기 전용 파일">
    `memory.json`, `design-intelligence.json`, `KNOWLEDGE.md`, `template.json`
  </Accordion>
</AccordionGroup>

이 파일을 잠금 해제하는 설정은 없습니다. `index.html`은 앱을 로드하는 셸일 뿐입니다. 모든 보이는 페이지, 헤더, 푸터, 링크는 `src/` 아래에 있으며, `main.tsx`, `index.css`, `vite-env.d.ts`를 제외하고 모두 편집 가능합니다.

## 분석 및 추적 스니펫

Google Tag Manager, Google 태그, 또는 Meta Pixel을 추가해야 하는 경우, head 마크업을 직접 편집하는 대신 **설정 → 일반**의 **분석** 카드를 사용하세요. [설정](/ko/settings)을 참조하세요.

## 중요한 경고 사항

<Warning>
  기록 내부에 있을 때(실행 취소 후) 한 수동 편집은 다음 실행 취소, 다시 실행, 또는 복원 작업에서 폐기됩니다. 수정 기록에 대한 자세한 내용은 [미리보기](/ko/preview)를 참조하세요.
</Warning>

<Info>
  AI 생성 이미지는 `public/images/generated/`에 저장됩니다. 코드에서 참조할 수 있지만, 채팅 외부에서 이동하거나 이름을 바꾸면 AI가 이를 추적하지 못할 수 있습니다.
</Info>
