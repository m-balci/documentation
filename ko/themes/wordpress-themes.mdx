웹사이트를 구축하는 데 사용하는 것과 동일한 채팅에서 설치 가능한 WordPress Full Site Editing(FSE) 블록 테마를 생성합니다. 브라우저에서 실시간으로 미리보고, `.zip`으로 다운로드한 뒤, WordPress 6.7 이상이 실행 중인 어떤 사이트에도 설치할 수 있습니다.

<Note>
  WordPress 테마는 Plus 및 Premium 요금제에서 사용할 수 있습니다.
</Note>

## 제공되는 것

WordPress 테마 프로젝트는 웹사이트 대신 블록 테마를 생성합니다. 테마에는 다음이 포함됩니다.

- 디자인 시스템의 색상, 폰트, 간격이 담긴 `theme.json`
- 블록 템플릿과 템플릿 파트
- 패턴
- 스타일

Webza는 모든 빌드에서 테마의 구조와 PHP 구문을 검사하므로, 다운로드한 테마는 설치할 준비가 된 상태입니다.

## WordPress 테마 프로젝트 생성하기

대시보드에서 프롬프트 옆에 출력 선택기가 표시됩니다.

| 출력 유형 | 결과 |
| --- | --- |
| **웹사이트** | 기본값입니다. 서브도메인이나 사용자 지정 도메인에 게시할 수 있는 사이트입니다. |
| **WordPress 테마** | 설치 가능한 FSE 블록 테마입니다. |

**WordPress 테마**를 선택하고 프롬프트를 입력한 뒤 프로젝트를 시작하세요. 출력 유형은 프로젝트 생성 시 설정되며, 이후 변경할 수 없습니다.

<Tip>
  WordPress 템플릿부터 시작할 수도 있습니다. WordPress용 템플릿은 웹사이트 템플릿 옆에 표시됩니다.
</Tip>

## 테마 미리보기

Webza는 WordPress Playground에서 테마를 미리봅니다: 브라우저에서 실행되는 실제 WordPress에 테마가 설치되고 활성화된 상태입니다. 서버나 호스팅 없이도 결과를 확인할 수 있습니다.

Playground에는 자체적인 새로고침 컨트롤이 있습니다. 완전한 WordPress 인스턴스를 부팅하므로, 첫 로딩과 미리보기 업데이트는 시간이 조금 걸릴 수 있습니다.

<Warning>
  Playground은 미리보기 도구이며 호스팅이 아닙니다. 그 안의 모든 것은 브라우저 탭에만 존재하며, 탭을 닫으면 사라집니다. 테마를 사용하려면 `.zip`을 다운로드하여 자신의 WordPress 사이트에 설치하세요.
</Warning>

## 편집 및 반복

실행 취소, 다시 실행, 수정 기록은 웹사이트와 동일하게 테마 프로젝트에서도 작동합니다. 수정 기록에서 특정 버전을 복원하면, Playground 미리보기가 복원된 테마로 다시 부팅되어 해당 시점부터 계속 편집할 수 있습니다.

## 다운로드 및 설치

<Steps>
  <Step title="테마 다운로드">
    Webza 에디터에서 프로젝트를 열고 **테마 다운로드**를 클릭하세요. `.zip` 파일은 프로젝트 이름으로 생성됩니다.
  </Step>
  <Step title="WordPress에 업로드">
    WordPress 관리자에서 **Appearance → Themes → Add New**로 이동한 뒤 **Upload Theme**를 클릭하세요. 다운로드한 `.zip` 파일을 선택하고 **Install Now**를 클릭하세요.
  </Step>
  <Step title="활성화">
    설치가 완료되면 **Activate**를 클릭하여 테마를 사이트에 적용하세요.
  </Step>
</Steps>

<Tip>
  다운로드한 파일 이름을 보관하세요. WordPress는 `.zip` 파일 이름을 테마 폴더 이름으로 사용합니다.
</Tip>

### 요구사항

- **WordPress 6.7 이상.** 이전 버전은 설치를 거부하거나 템플릿을 잘못 표시할 수 있습니다.
- WordPress 서버에 **PHP 7.4 이상**이 필요합니다.

## 테마 프로젝트에서 사용할 수 없는 기능

테마는 다운로드 가능한 파일이며 호스팅되는 사이트가 아니므로, 일부 웹사이트 기능은 사용할 수 없습니다.

- **게시 및 사용자 지정 도메인**: Webza는 테마 프로젝트를 호스팅하지 않으므로, **도메인** 탭이 표시되지 않습니다.
- **GitHub 및 Supabase**: 테마에서는 사용할 수 없습니다.
- **디자인 모드**: 생성 시 선택한 디자인 시스템이 `theme.json`에 내장됩니다.
- **AI 생성 이미지**: 웹사이트 프로젝트에서만 사용할 수 있습니다.
- **분석**: 분석 카드가 숨겨집니다. 추적 기능은 WordPress 사이트에 직접 추가하세요.

에디터에서는 **내보내기** 버튼이 **테마 다운로드**로 대체됩니다.

## 요금제 변경

Plus 또는 Premium에서 WordPress 테마가 포함되지 않은 요금제로 변경하면, 기존 테마는 여전히 다운로드할 수 있지만 테마 프로젝트의 새로운 빌드는 차단됩니다. 다시 편집하려면 요금제를 업그레이드하세요.
