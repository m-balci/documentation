미리보기 패널은 프로젝트의 라이브 뷰를 보여줍니다. 뷰포트 크기를 조정하고, 요소를 검사하고, 디자인 테마를 변경하고, 수정 기록을 탐색할 수 있습니다. 빌드가 완료되면 미리보기가 자동으로 다시 로드되므로 수동 새로고침 버튼이 필요 없습니다.

웹사이트 프로젝트에서는 미리보기가 백그라운드에서 빌드됩니다. 다시 빌드, 실행 취소, 다시 실행, 복원, 스타일 편집, 디자인 변경에 대해 즉시 반환되며, 작은 **Updating preview** 표시기가 나타납니다. 그 사이에 보낸 메시지는 더 이상 미리보기 빌드를 기다리지 않습니다. 미리보기 업데이트에 실패하면 마지막으로 작동하는 미리보기가 유지됩니다.

## 뷰포트 제어

뷰포트 버튼을 사용하여 프로젝트가 다른 크기에서 어떻게 보이는지 테스트하세요.

| 버튼 | 기능 |
| --- | --- |
| **휴대폰** | 미리보기를 모바일 너비로 축소합니다. |
| **태블릿** | 휴대폰과 데스크톱 사이의 중간 너비로 설정합니다. |
| **전체 너비** | 미리보기를 패널 전체 너비로 확장합니다. |

## 검사 모드

**검사**를 클릭하여 검사 모드를 켜거나 끕니다. 검사 모드가 켜지면 미리보기의 어떤 요소를 클릭해도 요소 검사 도구 모음이 열립니다.

도구 모음 작업은 선택한 요소에 따라 다릅니다:

- **텍스트 편집** (텍스트 요소만): 요소 텍스트를 인라인으로 편집합니다. 변경 사항은 보류 중인 변경 사항 표시줄에 대기합니다.
- **이미지** (`<img>` 요소만): 파일을 업로드하거나 이미지 URL을 붙여넣어 이미지 소스를 교체합니다. 변경 사항은 보류 중인 변경 사항 표시줄에 대기합니다.
- **스타일**: 색상, 간격, 크기 등 인라인 스타일을 미세 조정합니다. 스타일 편집은 AI 없이 자체적으로 적용됩니다.
- **AI 편집**: 요소를 지시사항과 함께 AI에 보냅니다. 변경 사항은 보류 중인 변경 사항 표시줄에 대기합니다.
- **닫기**: 검사기를 닫습니다.

### 보류 중인 변경 사항 표시줄

검사기에서 **텍스트 편집**, **이미지**, 또는 **AI 편집** 변경을 하면 미리보기 하단에 보류 중인 변경 사항 표시줄이 나타납니다. 대기 중인 변경 사항 수와 두 가지 작업이 표시됩니다:

- **모두 저장**: 배치를 AI에 보내고, 빌드를 실행하고, 크레딧을 소비합니다.
- **모두 취소**: 대기 중인 모든 변경 사항을 제거합니다.

<Warning>
  **모두 저장**을 클릭하기 전까지 아무것도 적용되지 않습니다. 저장하기 전에 떠나면 대기 중인 변경 사항이 사라집니다. 수정 사항을 모아 한 번에 저장하여 추가 크레딧 사용을 피하세요.
</Warning>

<Note>
  **스타일** 편집은 AI 없이 소스를 직접 변경하며, 보류 중인 변경 사항 표시줄에 대기하지 않습니다.
</Note>

## 디자인 모드

**디자인**을 클릭하여 이미 빌드된 사이트의 테마를 변경합니다.

1. 디자인 시스템을 선택합니다.
2. 원하는 경우 강조색 팔레트를 선택합니다.
3. **AI에게 물어보기**를 클릭하여 새 테마를 적용합니다.

이것은 재빌드를 트리거합니다. 미리보기는 실제 디자인으로 다시 로드되고, AI는 하드코딩된 색상에 대한 수정 패스를 실행합니다. 채팅 요청처럼 빌드 크레딧을 소비합니다. 다른 빌드가 이미 실행 중일 때는 디자인 변경을 적용할 수 없습니다.

<Info>
  디자인 모드는 웹사이트에만 사용할 수 있습니다. 생성 시 선택한 디자인 시스템을 유지하는 WordPress 및 Shopify 테마 프로젝트에는 숨겨져 있습니다.
</Info>

## 실행 취소 및 다시 실행

**실행 취소** 및 **다시 실행** 버튼을 사용하여 프로젝트 기록을 탐색합니다. 다음 키보드 단축키도 사용할 수 있습니다:

| 작업 | 단축키 |
| --- | --- |
| 실행 취소 | Ctrl/Cmd + Z |
| 다시 실행 | Ctrl/Cmd + Shift + Z 또는 Ctrl + Y |

각 실행 취소는 정확히 하나의 변경 사항을 되돌립니다: AI 채팅 요청, 스타일 편집, 또는 디자인 테마 변경. 실행 취소 후 프로젝트가 재빌드됩니다. 실행 취소 전에 최신 작업이 체크포인트에 저장되므로 다시 실행으로 되돌릴 수 있습니다. 각 실행 취소와 다시 실행은 채팅에 기록되어 AI가 인지할 수 있습니다.

<Warning>
  빌드가 실행 중일 때는 실행 취소와 다시 실행을 사용할 수 없습니다. 완전히 새로운 프로젝트는 두 번째 변경 전까지 실행 취소할 것이 없습니다.
</Warning>

<Warning>
  기록 내부에 있을 때(실행 취소 후) 코드 편집기에서 한 수동 편집은 캡처되지 않습니다. 다음 실행 취소나 복원은 경고 없이 이를 폐기합니다. 먼저 최신 상태로 돌아가거나 AI가 변경하도록 하세요.
</Warning>

<Info>
  Shopify 프로젝트의 경우 **실행 취소**, **다시 실행**, **수정 기록** 버튼이 숨겨져 있습니다. <strong>테마 다운로드(.zip)</strong>만 표시됩니다. Shopify 프로젝트에서도 키보드 단축키는 여전히 작동합니다.
</Info>

## 수정 기록

**시계 아이콘**을 클릭하여 수정 기록을 엽니다. 모든 AI 요청, 스타일 편집, 디자인 변경 전에 체크포인트가 캡처됩니다. Webza는 최근 20개의 체크포인트를 보관합니다.

목록에는 레이블, 타임스탬프, 파일 수가 표시됩니다. 현재 버전에는 **현재** 배지가 있습니다. 아무 버전에서 **복원**을 클릭하면 해당 버전으로 이동합니다.

복원은 먼저 현재 상태를 체크포인트에 저장하므로 복원을 되돌릴 수 있습니다. 각 복원은 재빌드를 트리거합니다. 수정 기록은 웹사이트와 WordPress 테마에만 사용할 수 있습니다.

<Note>
  게시 스냅샷은 수정 기록과 별개입니다. 자세한 내용은 [게시](/ko/publish) 페이지를 참조하세요.
</Note>

## WordPress Playground 미리보기

WordPress 테마 프로젝트는 WordPress Playground 내부에서 미리보기됩니다. Playground에는 자체 다시 로드 제어가 있으므로 자동 미리보기 다시 로드 동작이 다르게 작동합니다.
