---

Webza로 첫 웹사이트를 만들고 인터넷에 게시하는 데 약 10분이면 충분합니다. 설치할 것도, 설정할 것도 없습니다. 원하는 것을 설명하면 Webza가 디자인하고 만들어주며, 공유할 수 있는 실제 주소에 게시합니다. 이 가이드에서는 가상의 동네 빵집 **Golden Crust**를 위한 웹사이트를 만들어 봅니다. 홈페이지, 가격이 포함된 메뉴, 주문 양식이 있습니다. 언제든지 자신의 아이디어로 바꿀 수 있으며, 과정은 동일합니다.

Webza로 제작할 때는 [크레딧](/ko/credits-and-usage)을 사용하며, 무료 요금제에는 일회성 200만 AI 크레딧이 포함됩니다. 각 요금제에 포함된 기능은 [요금제](/ko/subscription-plans)에서 확인하세요.

<Steps>
  <Step title="계정 만들기">
    이메일, Google, GitHub으로 [무료 가입](https://webza.ai/register?utm_source=webza_docs&utm_medium=content)하세요. Webza가 제작 준비가 된 대시보드를 열어줍니다. 로그인, 비밀번호 재설정, 계정 설정에 대한 자세한 내용은 [계정 만들기](/ko/introduction/create-an-account)를 참조하세요.
  </Step>
  <Step title="웹사이트 설명하기">
    [대시보드](/ko/introduction/dashboard-overview)의 프롬프트 입력란은 모든 프로젝트의 시작점입니다. 평범한 언어로 원하는 웹사이트를 설명하세요.

    다음 프롬프트를 사용하거나 자신의 아이디어에 맞게 수정해 보세요:

    ```text Prompt wrap
    Build a website for Golden Crust, a neighborhood bakery. Include a warm hero section with a headline and an "Order online" button, a menu page with sourdough, croissants, and cinnamon rolls with prices, an About section with the bakery's story, and an order form where visitors enter their name, the items they want, and a pickup time. Use realistic sample content. Cozy, modern design. Works well on mobile.
    ```

    <Tip>
      페이지, 섹션, 원하는 느낌을 구체적으로 설명하세요. 첫 프롬프트에 더 많은 맥락을 제공할수록 첫 버전이 상상했던 것에 더 가까워집니다.
    </Tip>

    <Accordion title="자신의 아이디어 사용하기">
      다음 시작 예시 중 하나를 수정하거나 처음부터 직접 프롬프트를 작성하세요. 이 가이드의 단계는 동일합니다.

      ```text Portfolio wrap
      Build a portfolio website for a freelance photographer: a full-width gallery, an About page, a services and pricing section, and a contact form. Minimal, elegant design.
      ```

      ```text Local business wrap
      Build a website for a dental clinic: a homepage with services, a team section with photos, opening hours, a location section, and an appointment request form. Clean, trustworthy design.
      ```

      ```text Landing page wrap
      Build a landing page for a mobile app that helps people track their daily water intake: a hero with a download button, a features section, testimonials, and an FAQ. Fresh, bright design.
      ```
    </Accordion>
  </Step>
  <Step title="첫 버전이 나타나는 것을 지켜보기">
    Webza가 프로젝트를 만들고 제작을 시작합니다. 첫 버전은 몇 분 정도 걸립니다.

    준비가 되면 [편집기](/ko/editor)에서 작업합니다. Webza와 대화하는 [프로젝트 채팅](/ko/project-chat)이 웹사이트가 실시간으로 실행되는 [미리보기](/ko/preview) 옆에 있습니다. 미리보기를 클릭하고 메뉴를 열고 섹션을 스크롤해 보세요.
  </Step>
  <Step title="변경하기">
    프로젝트 채팅에서 한 번에 하나씩 변경을 요청하고, 매번 미리보기를 확인하세요. 예를 들어:

    ```text Prompt wrap
    Add a "Today's specials" section above the menu that highlights two items with a short description and price.
    ```

    웹사이트는 작동하지만 상상했던 모습이 아니라면, 평범한 말로 그렇게 말하세요. 다음과 같은 프롬프트도 완벽합니다:

    ```text Prompt wrap
    Make the whole site feel warmer and less corporate.
    ```

    [편집기](/ko/editor)에서 시각적으로 편집하거나, [코드 편집기](/ko/code-editor)를 열어 사이트 파일을 완전히 제어할 수도 있습니다. [게시](/ko/publish)하기 전까지 변경 사항은 비공개로 유지됩니다.
  </Step>
  <Step title="작동 여부 확인하기">
    게시하기 전에 몇 분 정도 웹사이트를 테스트하세요:

    - 모든 버튼과 링크를 클릭해 보세요.
    - 주문 양식을 작성하여 모든 필드가 작동하는지 확인하세요.
    - 휴대폰에서 사이트가 어떻게 보이는지 확인하세요. 대부분의 방문자는 모바일로 링크를 엽니다.

    문제가 있다면 Webza에게 정확히 무엇이 잘못되었고 어디에 있는지 알려주세요:

    ```text Prompt wrap
    On the menu page, the "Order online" button does nothing. It should scroll to the order form.
    ```
  </Step>
  <Step title="게시">
    편집기에서 **게시**를 선택합니다. 다른 프로젝트 작업 버튼 옆에 있습니다. 짧은 배포 후, 웹사이트는 무료 `webza.ai` 하위 도메인(예: `golden-crust.webza.ai`)에서 라이브 상태가 되어 공유할 준비가 됩니다. 자세한 내용은 [사이트 게시](/ko/publish)를, 자신의 도메인을 사용하는 방법은 [커스텀 도메인](/ko/custom-domains)을 참조하세요.

    <Note>
      **라이브 사이트는 스냅샷입니다.** 게시 후 변경한 내용은 미리보기에 바로 표시되지만, 라이브 사이트는 다시 게시할 때만 업데이트됩니다.
    </Note>
  </Step>
</Steps>

이것이 전체 루프입니다: 설명하고, 다듬고, 게시합니다. Webza로 만드는 모든 웹사이트는 아무리 야심 차더라도 이 루프를 반복하는 것입니다.
