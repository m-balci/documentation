대시보드는 Webza의 출발점입니다. 새 프로젝트를 시작하고, 기존 프로젝트를 열고, 크레딧 잔액을 확인하고, 결제, 지원, 설정 등 계정 도구에 접근하는 곳입니다.

## 새 프로젝트 시작하기

프롬프트 입력란은 대시보드 중앙, **무엇을 만들어 드릴까요?** 인사말 아래에 있습니다. 만들고 싶은 것을 설명하고 **시작**을 선택하면 프로젝트가 생성되고 채팅이 열립니다. 전체 단계별 안내는 [빠른 시작](/ko/introduction/getting-started)을 참조하세요.

### 프롬프트 입력란

텍스트 필드에 아이디어를 입력하세요. 간단하게 `a portfolio website for a photographer`처럼 짧게 적어도 되고, 각 페이지와 섹션을 여러 문단으로 상세히 설명해도 됩니다. 기능, 디자인 선호도, 요구사항을 더 구체적으로 설명할수록 첫 결과가 더 좋아집니다. 입력란에는 다음 기능도 포함됩니다:

- **출력 유형**: 프롬프트 옆의 선택기(기본값은 **웹사이트**)가 Webza가 만들 것을 선택합니다. 요금제에 WordPress 또는 Shopify 테마가 포함된 경우(Plus 및 Premium) 표시됩니다:
  - **웹사이트**: Webza에서 호스팅하는 사이트입니다.
  - **WordPress 테마**: 설치 가능한 WordPress 블록 테마입니다. 브라우저 기반 WordPress Playground에서 미리보고 테마 `.zip`으로 내보냅니다.
  - **Shopify 테마**: 설치 가능한 Shopify Online Store 2.0 테마입니다. 테마 `.zip`을 다운로드하여 Shopify 스토어에 설치합니다.
- **사용자 지정**: 시작점에 대한 모든 옵션이 들어 있는 팝오버를 엽니다. [프로젝트 사용자 지정](#프로젝트-사용자-지정)을 참조하세요.
- **마이크로폰**: 브라우저 기반 음성 입력을 사용하여 손을 쓰지 않고 프로젝트를 설명합니다.
- **첨부**: 로고, 사진, PDF 등 최대 10개의 파일을 첫 프롬프트에 첨부합니다. 파일 첨부는 파일 저장소가 포함된 요금제에서 사용할 수 있으며, 각 파일은 프로젝트 생성 전에 요금제의 파일 크기, 유형, 저장소 제한에 대해 검사됩니다.
- **시작**: 프로젝트를 만들고 채팅을 엽니다.

<Note>
  첫 프롬프트는 이후 채팅 메시지와 마찬가지로 최대 10,000자까지 입력할 수 있습니다. 한도에 가까워지면 카운터가 표시됩니다.
</Note>

### 프로젝트 사용자 지정

**사용자 지정** 팝오버에는 시작점에 대한 모든 선택기가 있습니다:

- **템플릿**: 프로젝트가 시작하는 구조, 즉 어떤 페이지와 컴포넌트가 존재하는지를 의미합니다. **자동**으로 두면 AI가 빌드 시점에 하나를 선택하고, 특정 템플릿을 선택할 수도 있습니다. 프리미엄 템플릿은 Plus 및 Premium 요금제에서 사용할 수 있습니다. [템플릿](/ko/templates)을 참조하세요.
- **디자인 시스템**: 사이트의 시각적 정체성인 색상 토큰, 강조색 팔레트, 글꼴입니다. **자동**으로 두면 AI가 첫 빌드 시 프롬프트에 가장 잘 맞는 것을 선택하고, 특정 디자인 시스템을 선택하여 외관을 고정할 수도 있습니다. Substrate와 10개의 프리미엄 디자인 시스템이 모든 요금제에서 사용 가능합니다. [디자인 시스템](/ko/design-systems)을 참조하세요.
- **강조색**: 특정 디자인 시스템을 선택하면 해당 이름이 지정된 강조색 팔레트 중 하나를 선택하거나 기본 강조색을 유지할 수 있습니다.
- **데이터베이스**: Supabase 연결 중 하나를 첨부하여 앱에 데이터베이스를 연결합니다. [데이터베이스](#프로젝트)를 참조하세요.
- **통합**: GitHub 저장소를 연결합니다.

템플릿과 디자인 시스템은 독립적이므로 어떤 디자인 시스템이든 어떤 템플릿이든 조합할 수 있습니다. WordPress 및 Shopify 테마의 경우 데이터베이스와 GitHub 옵션은 적용되지 않습니다.

### 제안 프롬프트

프롬프트 입력란 아래에는 **포트폴리오 웹사이트 만들기**, **랜딩 페이지 디자인하기**, **전자상거래 스토어 만들기** 등의 제안이 스크롤됩니다. 하나를 선택하면 프롬프트 입력란이 채워지고, 수정하거나 바로 시작할 수 있습니다.

## 사이드바 및 탐색

왼쪽 사이드바에서 계정의 모든 것에 접근할 수 있습니다.

- **만들기**: 대시보드 프롬프트 입력란으로 돌아가 새 프로젝트를 시작합니다.

### 프로젝트

**프로젝트** 섹션은 제목 옆의 화살표로 접을 수 있습니다.

- **모든 프로젝트**: 프로젝트를 탐색하고, 즐겨찾기에 추가하고, 복제하고, 삭제합니다. [프로젝트 관리](#프로젝트-관리)를 참조하세요.
- **파일 관리자**: 이미지와 문서 등 파일을 업로드하고, 이미지와 PDF를 인라인으로 미리보고, 파일을 삭제하고, 저장소 사용량을 확인합니다. 저장소 및 파일 크기 제한은 요금제에 따라 다르며 전체 계정에 적용됩니다. [파일 관리자](/ko/file-manager)를 참조하세요.
- **데이터베이스**: 자신의 Supabase 연결을 추가합니다. 활성화된 기능에 따라 Supabase에 로그인하여 연결(**Supabase 연결**), 프로젝트 범위 액세스 토큰을 붙여넣기, 또는 연결 문자열로 수동 연결할 수 있습니다. 연결을 사용하는 앱은 관계형 Postgres 테이블, 인증, 저장소, 행 수준 보안(RLS)을 얻습니다. [Supabase](/ko/integrations/supabase)를 참조하세요.
- **GitHub**: 새 비공개 저장소를 만들거나 이미 소유한 빈 저장소를 첨부하여 GitHub 저장소를 프로젝트에 연결합니다. 자동 푸시가 켜진 경우, Webza는 각 빌드 후 생성된 소스 코드를 저장소에 푸시합니다. 나중에 프로젝트 설정에서 저장소를 연결, 전환 또는 연결 해제할 수 있습니다. [GitHub](/ko/integrations/github)를 참조하세요.
- **API 키**: 읽기 전용 Webza REST API용 개인 API 키를 만듭니다. 각 키는 생성 시 한 번만 표시되며, 30일, 90일, 365일 후에 만료될 수 있고 최대 10개의 키를 보유할 수 있습니다. API 접근은 Plus 및 Premium 요금제에서 사용할 수 있습니다. [개인 API](/ko/integrations/personal-api)를 참조하세요.
- **API 문서**: curl, JavaScript, PHP, Python용 대화형 테스터와 복사-붙여넣기 샘플이 포함된 모든 API 엔드포인트를 나열합니다. API는 계정, 크레딧, 구독, 프로젝트, 알림, 인보이스를 노출합니다.
- **결제**: 요금제, 크레딧, 사용량, 거래 내역을 보거나 구독을 취소합니다. [인보이스 및 결제](/ko/invoices-and-billing)와 [구독 변경 또는 취소](/ko/change-or-cancel-your-subscription)를 참조하세요.
- **지원**: 지원 티켓을 열고 추적합니다. [지원 티켓](/ko/help/support-tickets)을 참조하세요.
- **설정**: 계정, AI 설정, 개인정보를 관리합니다. [설정](/ko/settings)을 참조하세요.

<Warning>
  API는 읽기 전용입니다: 프로젝트를 만들거나, 빌드를 트리거하거나, 결제를 변경할 수 없습니다. API 키를 비밀로 유지하세요. 키는 취소하거나 만료될 때까지 계정 데이터에 접근할 수 있습니다.
</Warning>

### 투어 다시 시작

대시보드를 처음 열면 먼저 필요한 인터페이스 부분을 안내하는 짧은 가이드 투어가 시작될 수 있습니다. 단계별로 진행하거나 닫을 수 있습니다. 언제든지 사이드바 하단의 **투어 다시 시작**을 선택하여 다시 재생할 수 있습니다. 프로젝트 내부에서는 편집기 도구 모음 오른쪽의 원형 화살표 버튼(**다시 빌드** 옆)을 눌러 편집기 투어를 다시 재생할 수 있습니다.

## 프로젝트 관리

**모든 프로젝트**는 프로젝트를 세 개의 탭에 각각 카운트와 함께 표시합니다:

- **전체**: 작업 중인 모든 프로젝트.
- **즐겨찾기**: 행에서 별표로 표시한 프로젝트입니다. 별표 표시는 편의를 위한 필터일 뿐 프로젝트를 변경하지 않습니다.
- **휴지통**: 삭제된 프로젝트입니다. **복원**을 선택하여 되살리거나, **영구 삭제**를 선택하여 지금 완전히 제거합니다.

각 프로젝트 행에는 **복제**가 포함된 작업 메뉴도 있으며, 이는 `<원본> (Copy)`라는 이름의 새 프로젝트를 만듭니다. 자세한 내용은 [프로젝트 찾기](/ko/find-a-project)를 참조하세요.

<Warning>
  휴지통의 프로젝트는 보관 기간이 지나면 파일, 미리보기, 스냅샷과 함께 영구 삭제됩니다. 영구 삭제는 되돌릴 수 없습니다. {/* TODO: Confirm Webza's trash retention period (script default is 90 days). */}

## 도움 받기

사이드바에서 **지원**을 선택하여 티켓을 보고, **새 티켓**을 선택하여 새 티켓을 엽니다. 제목을 추가하고, 문제를 설명하고, 오류 스크린샷 등 파일을 첨부합니다. 답변은 이메일로 도착하며 티켓에 스레드로 정리됩니다.

티켓은 지원팀이 작업 중일 때 **열림** 상태이고, 사용자의 답변을 기다릴 때 **보류 중**이며, 완료되면 **닫힘** 상태입니다. 닫힌 티켓에 답변하면 다시 열리므로 중복 티켓을 만들 필요가 없습니다. 모든 멤버가 티켓을 열 수 있으며, Plus와 Premium에는 우선 지원이 포함됩니다.

<Tip>
  티켓은 사용자와 Webza 팀만 읽을 수 있으므로 계정별 세부 정보를 적기에 적합한 곳입니다. 명시적으로 요청받지 않은 한 비밀번호나 API 키를 붙여넣지 마세요.
</Tip>
