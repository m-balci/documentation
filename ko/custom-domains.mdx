**사용자 지정 도메인**을 사용하면 방문자가 기본 `webza.ai` 하위 도메인(예: `golden-crust.webza.ai`) 대신 자신의 주소(예: `goldencrust.com`)로 Webza 웹사이트에 접근할 수 있습니다. Webza는 도메인을 판매하지 않습니다. 도메인은 모든 도메인 공급업체(등록 기관)에서 구매한 후 프로젝트에 연결하면 됩니다. 이 페이지에서는 도메인 연결, 인증 및 문제 해결 방법을 안내합니다.

사용자 지정 도메인은 웹사이트의 다음을 개선합니다.

- **브랜드 아이덴티티**: 사이트가 더 전문적이고 신뢰할 수 있게 보입니다.
- **검색 가시성**: 직접 관리하는 도메인 아래에서 콘텐츠 권위를 쌓습니다.
- **기억 용이성**: 짧고 브랜드화된 주소는 공유하고 기억하기 쉽습니다.

<Info>
  사용자 지정 도메인은 **Plus** 및 **Premium** 요금제에서 사용할 수 있습니다. 무료 요금제에서는 사용할 수 없습니다. 요금제 비교는 [구독 요금제](/ko/subscription-plans)를 참조하세요.
</Info>

## 시작하기 전에

다음 사항을 확인하세요.

- **소유한 도메인.** 아직 없다면 GoDaddy, Namecheap, Cloudflare 등의 도메인 공급업체에서 구매하세요.
- **도메인 DNS 설정에 대한 액세스 권한.** 소유권을 인증하려면 도메인 공급업체에 DNS 레코드를 추가해야 합니다. 다른 사람(예: IT 팀 또는 에이전시)이 도메인을 관리하는 경우 액세스를 요청하거나 레코드를 전달하세요.
- **게시된 프로젝트.** 언제든지 도메인을 연결할 수 있지만, 도메인은 [프로젝트를 게시](/ko/publish)한 후에만 웹사이트를 표시합니다.

## 도메인 연결하기

<Steps>
  <Step title="프로젝트 도메인 설정 열기">
    연결할 프로젝트를 연 다음 **설정 → 도메인 → 사용자 지정 도메인**으로 이동합니다.
  </Step>
  <Step title="도메인 입력하기">
    사용하려는 도메인(예: `goldencrust.com`)을 입력하고 계속합니다. `https://`나 끝에 슬래시 없이 도메인 이름만 입력하세요.
  </Step>
  <Step title="인증 화면 검토하기">
    Webza는 추가해야 할 DNS 레코드가 포함된 인증 화면을 표시합니다. 이 화면을 열어 두세요. 다음 단계에서 이 화면의 각 레코드를 도메인 공급업체에 복사합니다.
  </Step>
  <Step title="도메인 공급업체에서 DNS 레코드 추가하기">
    새 탭에서 도메인 공급업체에 로그인하고 도메인의 DNS 설정(때로는 **DNS 관리**, **DNS 영역** 또는 **고급 DNS**라고 함)을 엽니다. Webza 인증 화면의 모든 레코드에 대해 다음을 수행합니다.

    1. **레코드 추가**를 선택합니다.
    2. Webza에 표시된 것과 동일한 레코드 **유형**을 선택합니다.
    3. **호스트**(또는 **이름**)와 **값**(또는 **가리키는 대상**, **대상**, **콘텐츠**)을 표시된 그대로 정확히 복사합니다.
    4. 레코드를 저장합니다.

    <Tip>
      값은 직접 입력하지 말고 복사 버튼으로 복사하세요. 한 글자만 빠져도 인증 실패의 가장 흔한 원인입니다.
    </Tip>
  </Step>
  <Step title="도메인 인증하기">
    Webza로 돌아가 인증 화면에서 인증을 시작합니다. Webza는 DNS 레코드를 확인하고 도메인 소유권을 인증합니다.

    인증이 성공하면 도메인이 연결되고 게시된 웹사이트가 사용자 지정 도메인에서 로드되기 시작합니다.
  </Step>
</Steps>

<Note>
  DNS 변경 사항은 인터넷 전체에 전파되는 데 몇 분에서 최대 48시간이 걸릴 수 있습니다(이를 **DNS 전파**라고 합니다). 인증이 즉시 성공하지 않으면 잠시 기다렸다가 다시 시도하세요. 도메인을 제거했다가 다시 추가할 필요는 없습니다.
</Note>

## 다양한 공급업체에서 호스트 이름 작동 방식

도메인 공급업체는 호스트 필드를 다르게 표시합니다. Webza가 루트 도메인(예: `goldencrust.com`)에 대한 레코드를 표시할 때 공급업체는 호스트 필드에 다음 중 하나를 기대할 수 있습니다.

- `@`
- 빈 필드
- 전체 도메인 이름(예: `goldencrust.com`)

일부 공급업체는 호스트 끝에 도메인을 자동으로 추가합니다. 레코드의 호스트가 `www`이고 공급업체가 저장 후 `www.goldencrust.com`을 표시하면 이는 정상입니다. `www.goldencrust.com.goldencrust.com`이 표시되면 중복 부분을 제거하고 다시 저장하세요.

## 도메인 연결 후

- **새 주소를 공유하세요.** 사용자 지정 도메인을 명함, 소셜 프로필, 이메일 서명 등 모든 곳에서 사용하세요.
- **DNS 레코드를 그대로 유지하세요.** 추가한 레코드를 삭제하거나 변경하면 도메인이 웹사이트를 표시하지 않게 됩니다.
- **사이트를 업데이트하려면 게시하세요.** 라이브 사이트는 스냅샷입니다. 편집기에서 변경한 내용은 다시 게시한 후에만 사용자 지정 도메인에 표시됩니다. 자세한 내용은 [게시](/ko/publish)를 참조하세요.

## 문제 해결

<AccordionGroup>
  <Accordion title="인증이 계속 실패합니다">
    도메인 공급업체에서 다음 일반적인 원인을 확인하세요.

    - 레코드 **유형**이 Webza에 표시된 것과 정확히 일치합니다.
    - **값**이 완전히 복사되었으며 공백이나 누락된 문자가 없습니다.
    - **호스트**가 공급업체의 형식을 따릅니다. [다양한 공급업체에서 호스트 이름 작동 방식](#how-host-names-work-at-different-providers)을 참조하세요.
    - 레코드를 저장했습니다. 일부 공급업체는 별도의 **저장** 또는 **변경 사항 적용** 단계가 필요합니다.

    모든 것이 올바르게 보이면 DNS 전파를 기다렸다가 다시 인증하세요.
  </Accordion>

  <Accordion title="내 도메인이 여전히 이전 웹사이트를 표시합니다">
    도메인 공급업체에 이전 웹사이트 또는 호스팅 공급업체의 레코드가 남아 있을 가능성이 높습니다. 동일한 호스트를 가리키는 다른 곳으로 연결된 이전 레코드를 제거하여 Webza가 요청한 레코드만 남기세요. 그런 다음 DNS 전파를 기다리세요.
  </Accordion>

  <Accordion title="내 도메인이 빈 페이지나 오류를 표시합니다">
    프로젝트가 게시되었는지 확인하세요. 연결된 도메인은 [게시](/ko/publish)한 후에만 웹사이트를 표시합니다. 최근에 게시한 경우 몇 분 기다렸다가 페이지를 새로고침하세요.
  </Accordion>

  <Accordion title="Cloudflare를 사용하는데 사이트가 로드되지 않습니다">
    DNS가 Cloudflare에서 관리되는 경우, Webza에 추가한 레코드를 **Proxied**(주황색 구름) 대신 **DNS only**(회색 구름)으로 설정한 후 다시 인증하세요.
  </Accordion>

  <Accordion title="공급업체에서 DNS 설정을 찾을 수 없습니다">
    공급업체의 도움말 센터에서 "DNS 레코드 관리" 또는 "DNS 레코드 추가"를 검색하세요. 도메인이 다른 서비스(예: Cloudflare)의 네임서버를 사용하는 경우, 도메인을 구매한 등록 기관이 아닌 해당 서비스에서 레코드를 추가하세요.
  </Accordion>
</AccordionGroup>

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="Webza에서 도메인을 구매할 수 있나요?">
    아니요. Webza는 도메인을 판매하지 않습니다. 도메인은 모든 도메인 공급업체에서 구매한 후 이 페이지의 단계에 따라 프로젝트에 연결하세요.
  </Accordion>

  <Accordion title="사용자 지정 도메인을 연결한 후에도 webza.ai 하위 도메인을 유지하나요?">
    프로젝트는 `webza.ai` 하위 도메인을 유지합니다. 사용자 지정 도메인이 연결되면 방문자는 해당 도메인으로 웹사이트에 접근할 수 있습니다.
  </Accordion>

  <Accordion title="프로젝트를 게시하기 전에 도메인을 연결할 수 있나요?">
    네. 언제든지 도메인을 연결하고 인증할 수 있지만, 프로젝트를 게시한 후에만 웹사이트를 표시합니다.
  </Accordion>

  <Accordion title="도메인을 Webza로 이전해야 하나요?">
    아니요. 도메인은 현재 공급업체에 등록된 상태를 유지합니다. Webza 웹사이트를 가리키도록 DNS 레코드만 추가하면 됩니다. 도메인 비용 납부 및 갱신은 공급업체와 계속 진행합니다.
  </Accordion>

  <Accordion title="DNS, DNS 레코드, 전파는 무엇을 의미하나요?">
    - **DNS**는 브라우저가 도메인의 웹사이트 위치를 찾도록 안내하는 시스템입니다.
    - **DNS 레코드**는 도메인 설정의 항목으로, 도메인을 서비스로 연결하거나 소유권을 증명합니다.
    - **전파**는 DNS 변경 사항이 인터넷 전체에 업데이트되는 데 걸리는 시간으로, 보통 몇 분에서 몇 시간, 최대 48시간까지 걸릴 수 있습니다.
  </Accordion>
</AccordionGroup>
