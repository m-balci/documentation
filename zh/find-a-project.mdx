从侧边栏（在**项目**下）打开**所有项目**，查看您正在处理的每个项目、其状态以及继续工作的地方。此视图上还有一个**新建项目**按钮。

## 项目标签页

您的项目分为三个标签页组织，每个标签页都有计数：

| 标签页 | 显示内容 |
| --- | --- |
| **全部** | 您正在处理的每个项目 |
| **收藏** | 您从项目行中标记星号以固定到此处的项目（这纯粹是筛选，不会改变项目） |
| **回收站** | 已删除的项目，保留在恢复窗口中 |

## 收藏项目

点击任何项目行上的星号图标，将其固定到**收藏**标签页。这只是筛选。它不会改变项目设置、可见性或行为。

## 回收站和恢复

已删除的项目进入**回收站**标签页。每行提供**恢复**或**永久删除**。

<Warning>
  回收站会自动清空。回收站中的项目在保留期（默认 90 天）后与其文件、预览和快照一起被永久删除。无论是手动还是自动，永久删除都无法撤销。
</Warning>

删除项目会释放其子域名和自定义域名，以便重新使用。

## 复制项目

打开任何项目行上的操作菜单并选择**复制**，创建一个名为 "original (Copy)" 的副本。

### 复制的内容

- 名称和描述
- 原始提示
- 模板和输出类型（网站、WordPress 主题、Shopify 主题）
- 完整的对话历史和自定义指令
- 设计系统和强调色
- 发布标题、描述和公开/私密可见性

### 不复制的内容

副本以新的未发布项目开始：

- 没有子域名或自定义域名
- 没有分享图片
- 没有构建历史或存储用量
- 没有缩略图
- 没有分析 ID
- 新的 API 令牌
- 原始项目的任何 Supabase 或 GitHub 连接

副本是一个新的开始，而不是在线网站的克隆。它不会响应原始项目的域名。单独发布它并重新附加任何连接。这是必需的，因为子域名只属于一个项目，共享 API 令牌或仓库会让一个项目覆盖另一个项目的文件。

## 项目限制

- **Free** 和 **Plus** 套餐包含 1 个项目。
- **Premium** 包含无限项目。
