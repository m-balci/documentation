设计系统是网站的视觉标识。它将设计令牌（颜色、字体、间距、圆角和阴影）、一组命名强调色板、网页字体以及一份指导手册打包在一起，告诉 AI 如何应用外观。

[模板](/zh/templates)控制结构：您的网站有哪些页面和组件。设计系统控制外观。Webza 将两者结合，因此任何设计系统都可以搭配任何模板，同一个模板也可以呈现多种不同的外观。

<Info>
  所有套餐均可使用设计系统。Free、Plus 和 Premium 套餐上的自动选择、手动选择和设计模式的工作方式完全相同。
</Info>

## 工作原理

当 Webza 构建您的项目时，它从模板开始，然后将设计系统叠加在上面：

1. 模板提供页面结构和组件。
2. 应用设计系统的基础令牌、您选择的强调色板及其网页字体。
3. 某些设计系统包含特定组件的自有版本，这些版本会替换或优化模板的组件。
4. AI 遵循设计系统的指导手册，调整生成的代码以匹配外观。例如，它会替换硬编码颜色，使其遵循当前令牌和强调色。

每份指导手册还为整个网站设定一种统一的运动风格，因此动画在各板块之间感觉一致。

叠加是可预测的。选择不同的设计系统或强调色只会改变外观，而不会改变网站的结构。

## Substrate（默认）

Substrate 是 Webza 的默认设计系统。它是一种温暖、中性、高端的品牌风格，将 **Geist** 用于界面和正文文本，将衬线字体 **Newsreader** 用于编辑性强调。它使用 10 像素的圆角和柔和的分层阴影。

Substrate 有六种强调色板：

| 强调色 | 说明 |
| --- | --- |
| indigo | 默认强调色 |
| terracotta | 温暖、大地色调 |
| blue | 冷调、经典色调 |
| emerald | 绿色调 |
| ruby | 醒目的红色调 |
| mono | 中性、单色调 |

## 高级设计系统

除 Substrate 之外，Webza 还提供十种高级设计系统。每一种都是一套完整的外观，拥有各自的字体、颜色、阴影和个性。

| 设计系统 | 个性 |
| --- | --- |
| Aperture | 清晰、冷峻、建筑感 SaaS。精准而自信。 |
| Atrium | 值得信赖的企业级 SaaS。沉稳、可信、仪表盘级别。 |
| Bloom | 活泼欢快。厚重、圆润，搭配愉悦的糖果色强调。 |
| Botanica | 温暖、有机、编辑级 wellness。宁静而高端。 |
| Carbon | sleek 开发者工具。以深色为主，技术感，终端绿。 |
| Halcyon | 宁静、通透、梦幻粉彩。轻盈而安宁。 |
| Lumen | vibrant 现代金融科技辉光。发光、渐变、玻璃拟态。 |
| Monolith | bold 粗野瑞士编辑风。响亮、图形化、高对比度。 |
| Noir | dark 奢华与电影感。昂贵、克制、金属强调。 |
| Sandstone | 温暖、极简、编辑级。有灵魂的文学极简主义。 |

高级设计系统出现在 Substrate 可用的所有位置：**自定义**中的设计系统选择器、**自动**选择以及编辑器的设计模式。新的设计系统会随时间添加。

<Tip>
  许多设计系统包含风格指南预览：一个展示其字体、颜色、按钮和组件的页面。从设计系统选择器或编辑器的设计面板中打开它，在应用之前查看外观。
</Tip>

## 选择设计系统

设计系统和强调色可以通过以下三种方式之一选择。

### 自动（默认）

创建项目时，**自定义**弹窗中的设计系统选择器设置为**自动**。在首次构建时，AI 会选择最适合您提示的设计系统和强调色，并将该选择保存到项目中。

### 手动

在**自定义**弹窗中选择特定的设计系统，而不是**自动**。您还可以选择其强调色板之一，或保留其默认强调色。此后项目的每次构建都会使用该外观。

### 在编辑器中重新换肤

您可以随时在编辑器中切换已构建网站项目的设计系统或强调色。

<Steps>
  <Step title="打开设计面板">
    在编辑器中，切换到设计模式。**设计**面板会在预览旁边打开。
  </Step>
  <Step title="选择设计系统和强调色">
    选择一个新的设计系统，并可选选择一个强调色板。如果您想比较外观，可以先打开其风格指南预览。
  </Step>
  <Step title="点击询问 AI 应用">
    Webza 应用新的令牌和强调色并重新构建您的网站。预览会重新加载，然后 AI 会调整任何硬编码颜色，使整个网站匹配新外观。
  </Step>
</Steps>

重新换肤会像聊天请求一样消耗积分。当另一个构建正在运行时，您无法应用重新换肤。

<Note>
  设计模式仅适用于网站项目。对于 [WordPress](/zh/themes/wordpress-themes) 和 [Shopify](/zh/themes/shopify-themes) 主题项目，该模式会被隐藏。它们仍然使用创建时选择的设计系统，但您无法从编辑器中切换它。
</Note>

## 撤销重新换肤

重新换肤算作撤销和重做中的一个步骤，并会在修订历史中创建一个检查点。您可以稍后从预览中恢复它。请参阅[预览](/zh/preview)。
