用 Webza 构建您的第一个网站，并在大约十分钟内将其发布到互联网上。无需安装任何内容，也无需配置任何内容：您描述想要什么，Webza 负责设计和构建，然后您将其发布到一个可以分享的真实地址。在本指南中，您将为一家虚构的社区面包店 **Golden Crust** 创建一个网站，包含首页、带价格的菜单和订单表单。在任何步骤中都可以换成您自己的创意，流程保持不变。

在 Webza 中构建需要消耗[积分](/zh/credits-and-usage)，免费套餐包含一次性发放的 200 万 AI 积分。各套餐包含内容请参阅[订阅套餐](/zh/subscription-plans)。

<Steps>
  <Step title="创建账户">
    [免费注册](https://webza.ai/register?utm_source=webza_docs&utm_medium=content)，使用邮箱、Google 或 GitHub 均可。Webza 会打开您的控制台，准备开始构建。登录、密码重置和账户设置的详细信息请参阅[创建账户](/zh/introduction/create-an-account)。
  </Step>
  <Step title="描述您的网站">
    [控制台](/zh/introduction/dashboard-overview)上的提示框是每个项目的起点。用简单的语言描述您想要的网站。

    您可以尝试以下提示，或根据自己的创意进行调整：

    ```text Prompt wrap
    为 Golden Crust 这家社区面包店构建一个网站。包含一个温馨的 hero 区域，带有标题和"在线订购"按钮；一个菜单页面，展示酸面包、牛角包和肉桂卷及其价格；一个关于版块，讲述面包店的故事；以及一个订单表单，访客可以填写姓名、想要的商品和取货时间。使用逼真的示例内容。风格温馨、现代。在手机上表现良好。
    ```

    <Tip>
      具体描述页面、版块和您想要的感觉。在第一条提示中提供的上下文越多，第一版就越接近您设想的样子。
    </Tip>

    <Accordion title="使用您自己的创意">
      改编以下任一示例，或从头编写自己的提示。本指南中的步骤保持不变。

      ```text Portfolio wrap
      为一位自由摄影师构建作品集网站：全宽画廊、关于页面、服务与定价版块、联系表单。极简优雅的设计。
      ```

      ```text Local business wrap
      为一家牙科诊所构建网站：首页展示服务、团队照片版块、营业时间、位置版块和预约请求表单。干净、值得信赖的设计。
      ```

      ```text Landing page wrap
      为一款帮助人们追踪每日饮水量的移动应用构建落地页：hero 区域带下载按钮、功能版块、用户评价和常见问题。清新明亮的设计。
      ```
    </Accordion>
  </Step>
  <Step title="等待第一版生成">
    Webza 会创建您的项目并开始构建。第一版需要几分钟时间。

    准备好后，您将在[编辑器](/zh/editor)中工作：[项目聊天](/zh/project-chat)（您与 Webza 对话的地方）位于[预览](/zh/preview)（您的网站实时运行的地方）旁边。点击预览中的内容，打开菜单，滚动浏览各个版块。
  </Step>
  <Step title="做出修改">
    在项目聊天中一次请求一个修改，每次修改后检查预览。例如：

    ```text Prompt wrap
    在菜单上方添加一个"今日特惠"版块，突出展示两款商品及其简短描述和价格。
    ```

    如果网站功能正常但外观不符合您的设想，用简单的语言告诉它。这是一个完全有效的提示：

    ```text Prompt wrap
    让整个网站感觉更温馨，少一些 corporate 感。
    ```

    您也可以在[编辑器](/zh/editor)中进行可视化编辑，或打开[代码编辑器](/zh/code-editor)以完全控制网站文件。在[发布](/zh/publish)之前，您的更改保持私密。
  </Step>
  <Step title="检查功能是否正常">
    在发布之前，花几分钟测试您的网站：

    - 点击每个按钮和链接。
    - 填写订单表单，确保每个字段都能正常工作。
    - 检查网站在手机上的显示效果。大多数访客会通过手机打开您的链接。

    如果有问题，请准确告诉 Webza 哪里出了问题：

    ```text Prompt wrap
    在菜单页面上，"在线订购"按钮没有任何反应。它应该滚动到订单表单。
    ```
  </Step>
  <Step title="发布">
    在编辑器中选择**发布**，它位于其他项目操作旁边。经过短暂的部署后，您的网站将在免费的 `webza.app` 子域名上线（例如 `golden-crust.webza.app`），随时可以分享。详细信息请参阅[发布网站](/zh/publish)，使用自己的域名请参阅[自定义域名](/zh/custom-domains)。

    <Note>
      **您的在线网站是一个快照。** 发布后做出的更改会立即出现在预览中，但在线网站只有在再次发布时才会更新。
    </Note>
  </Step>
</Steps>

这就是整个流程：描述、优化、发布。您用 Webza 构建的每一个网站，无论多么宏大，都是这个流程的重复。
