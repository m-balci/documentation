## 比较套餐

每个套餐都针对不同类型的用户设计。

| 套餐 | 价格 | 最适合 |
| --- | --- | --- |
| **Free** | \$0.00/月 | 零成本探索 Webza |
| **Plus**（最受欢迎） | \$19.99/月 | 构建和发布单个项目 |
| **Premium** | \$49.99/月 | 无限项目，全功能 |

### 项目与 AI 积分

| 功能 | Free | Plus | Premium |
| --- | --- | --- | --- |
| 项目 | 1 | 1 | 无限 |
| AI 积分 | 2M（一次性） | 7M/月 | 20M/月 |
| 使用自己的 API 密钥 | — | ✓ | ✓ |
| 高级 AI 辅助 | — | ✓ | ✓ |
| Web Agent | ✓ | ✓ | ✓ |

关于积分的计算方式、充值和奖励积分，请参见[积分与用量](/zh/credits-and-usage)。

### 发布与域名

| 功能 | Free | Plus | Premium |

## 常见问题

<AccordionGroup>
  <Accordion title="如何升级、降级或取消我的套餐？">
    要升级或降级，请从菜单中的**支持**页面提交工单。要取消，请前往**账单**页面并选择**取消订阅**。您的套餐权益在当前计费周期结束前保持有效。详情请参见[更改或取消您的订阅](/zh/change-or-cancel-your-subscription)。
  </Accordion>

  <Accordion title="免费套餐的积分每月会刷新吗？">
    不会。免费套餐包含 2M AI 积分作为一次性赠送。Plus 和 Premium 每月都会提供新的积分配额。
  </Accordion>

  <Accordion title="我可以在免费套餐上连接自己的域名吗？">
    不可以。自定义域名在 Plus（1 个域名）和 Premium（3 个域名）套餐中可用。在免费套餐上，您可以发布到自定义的 `webza.app` 子域名。
  </Accordion>

  <Accordion title="我可以创建多少个项目？">
    Free 和 Plus 包含 1 个项目。Premium 包含无限项目。
  </Accordion>

  <Accordion title="我在哪里可以找到发票？">
    请参见[发票与账单](/zh/invoices-and-billing)。
  </Accordion>

  <Accordion title="我可以获得退款吗？">
    退款遵循 [Webza 服务条款](https://webza.ai/terms)。
  </Accordion>
</AccordionGroup>
