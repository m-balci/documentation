Webza 中的**设置**区域分为两部分：编辑器内的项目设置，以及侧边栏中的账户设置。用它们来配置您构建的内容和账户的行为方式。

## 项目设置

在编辑器中打开**设置**标签页。您看到的标签页取决于您的套餐和项目类型。

### 常规

设置塑造项目及其在线外观的基本参数。

| 字段 | 功能 |
| --- | --- |
| **项目名称** | 项目列表中的内部标签。 |
| **项目描述** | 帮助您记住用途的内部备注。 |
| **发布标题** | Title 标签和社交分享标题。 |
| **发布描述** | Meta 描述和社交分享文本。 |
| **可见性** | 公开（搜索引擎可索引）或私密（noindex）。 |
| **分享图片** | 用于 `og:image` 和 `twitter:image` 的社交预览图片。请参阅下文。 |
| **分析 ID** | 如果您的套餐包含分析功能，则为跟踪 ID。请参阅下文。 |
| **GitHub 仓库链接** | 如果启用了 GitHub，则为已连接仓库的链接。 |

#### 分享图片

上传 JPG、PNG 或 WebP 图片，最大 2 MB。推荐尺寸为 1200×630 像素。Webza 会在构建时将其写入 `og:image` 和 `twitter:image`。

<Tip>
  在广泛分享项目之前设置您的分享图片。社交平台会缓存首次抓取的内容，如果以后需要更新，某些平台提供缓存刷新工具。
</Tip>

复制的项目不会复制分享图片。您必须在新项目中重新上传。

#### 分析

如果您的套餐包含分析功能，**设置 → 常规**中会出现一个卡片，您可以添加：

- **Google Tag Manager 容器 ID**（格式 `GTM-XXXXXXX`）
- **Google 标签 ID**（格式 `G-…` 或 `AW-…`）
- **Meta Pixel ID**（8 到 20 位数字）

留空字段以禁用相应的跟踪器。它们在网站发布时注入到已发布的网站中。它们不会出现在编辑器预览或代码导出中。更改在下次请求时生效，无需重新构建。AI 无法为您移除这些标签。

<Note>
  对于其他服务（Hotjar、Clarity、LinkedIn、TikTok、自定义脚本），请添加 GTM 容器并在 GTM 内配置所有内容。
</Note>

此卡片对于 WordPress 和 Shopify 主题项目是隐藏的。请直接在您的 WordPress 网站或 Shopify 商店中添加跟踪。

### 域名

管理项目在互联网上的访问方式。

- **子域名**：每个已发布网站都会获得一个 `*.webza.app` 子域名。
- **自定义域名**：在**项目 → 设置 → 域名 → 自定义域名**中添加您自己的域名，然后添加所需的 DNS 记录并验证。

此标签页对于 WordPress 主题项目永远不会显示。更多信息请参阅[自定义域名](/zh/custom-domains)页面。

### 知识

添加最多 500 个字符的自定义指令。它们会在每次构建时发送给 AI。使用此字段记录您发现自己不断重复的持久规则：品牌语气、目标语言、要避免的库，或命名约定。

<Warning>
  保持简短。知识文本在每次构建时都要付费。一次性请求属于[项目聊天](/zh/project-chat)，不属于这里。
</Warning>

### 数据库

将您的某个 Supabase 连接附加到项目。您可以立即附加连接，以后切换到不同的连接，或随时分离。附加和切换需要您套餐上的数据库功能。分离始终允许，例如降级后。

只要连接处于附加状态，数据库标签页就会保持可见，即使您当前的套餐不再支持新的附加。

### 存储

此标签页显示项目文件和生成的应用用于回调 Webza 的 API 令牌。在没有文件存储的套餐上，标签页标记为 **API**，仅显示令牌。

### GitHub 仓库

连接仓库以自动推送源代码。

- **创建新的私有仓库**：Webza 会为您创建。
- **附加您拥有的空仓库**：连接现有的空仓库。

您可以随时切换到不同的仓库或断开连接。开启**自动推送**，在每次构建后推送源代码。

## 账户设置

点击侧边栏底部的**设置**打开您的账户面板。它有三个部分：账户、AI 设置和隐私。

### 账户

更新您的姓名和邮箱，或更改密码。您也可以在 [https://webza.ai/profile](https://webza.ai/profile) 管理您的个人资料。

### AI 设置

此部分在您使用自己的 API 密钥时，在 Plus 和 Premium 套餐上可用。

- **提供商**：选择提供商或保留**使用系统默认**以消耗 Webza 积分。
- **模型**：选择提供商后出现。
- **API 密钥**：加密存储并掩码显示。随时替换或移除密钥。保存密钥后会出现**已配置**徽章。
- **测试**：点击闪电按钮检查密钥是否有效。对于选定的提供商，它还会检查选定的模型。

使用您自己的密钥进行的构建由 Webza 计量，但不会从您的积分中扣除。您向 AI 提供商付费。如果切换回**使用系统默认**，保存的密钥会保留，您将恢复消耗积分。

#### 聊天音效

所有套餐都可用。选择 AI 工作时的通知音效风格：**极简**、**俏皮**、**复古**、**科幻**，或关闭音效。

### 隐私

- **Cookie 偏好**：管理您接受哪些 Cookie。
- **下载您的数据**：请求导出关于您账户的所有内容。此功能可能不可用。
- **删除您的账户**：请求删除。删除前有宽限期。如果自助删除关闭，系统会提示您联系支持。
