预览面板显示项目的实时视图。您可以调整视口大小、检查元素、重新设计主题，以及浏览修订历史。构建完成后预览会自动重新加载，因此您不需要手动刷新按钮。

## 视口控制

使用视口按钮测试项目在不同尺寸下的外观。

| 按钮 | 功能 |
| --- | --- |
| **手机** | 将预览缩小到手机宽度。 |
| **平板** | 设置为手机与桌面之间的中等宽度。 |
| **全宽** | 将预览扩展到面板全宽。 |

## 检查模式

点击**检查**切换检查模式。检查模式开启时，点击预览中的任何元素会打开元素检查器工具栏。

工具栏操作取决于您选择的元素：

- **编辑文本**（仅限文本元素）：内联编辑元素文本。更改会进入待处理更改栏的队列。
- **图片**（仅限 `<img>` 元素）：通过上传文件或粘贴图片 URL 替换图片来源。更改会进入待处理更改栏的队列。
- **样式**：调整内联样式，如颜色、间距和尺寸。样式编辑无需 AI 即可自行应用。
- **AI 编辑**：将元素连同指令发送给 AI。更改会进入待处理更改栏的队列。
- **关闭**：关闭检查器。

### 待处理更改栏

当您在检查器中进行**编辑文本**、**图片**或**AI 编辑**更改时，预览底部会出现待处理更改栏。它显示队列中的更改数量和两个操作：

- **全部保存**：将批量发送给 AI，运行构建，并消耗积分。
- **全部丢弃**：移除队列中的所有更改。

<Warning>
  在点击**全部保存**之前，什么都不会应用。如果在保存前离开，您将丢失队列中的更改。将调整批量处理并一次性保存，以避免额外消耗积分。
</Warning>

<Note>
  **样式**编辑直接更改源代码，无需 AI，不会进入待处理更改栏的队列。
</Note>

## 设计模式

点击**设计**为已构建的网站重新设计主题。

1. 选择一个设计系统。
2. 可选选择一个强调色板。
3. 点击**询问 AI**应用新主题。

这会触发重新构建。预览会以实际设计重新加载，AI 会运行修复流程处理硬编码颜色。它会像聊天请求一样消耗构建积分。当另一个构建正在运行时，您无法应用设计更改。

<Info>
  设计模式仅适用于网站。对于 WordPress 和 Shopify 主题项目它是隐藏的，这些项目保留创建时选择的设计系统。
</Info>

## 撤销和重做

使用**撤销**和**重做**按钮浏览项目历史。您也可以使用以下键盘快捷键：

| 操作 | 快捷键 |
| --- | --- |
| 撤销 | Ctrl/Cmd + Z |
| 重做 | Ctrl/Cmd + Shift + Z 或 Ctrl + Y |

每次撤销会回退一个更改：AI 聊天请求、样式编辑或设计主题更改。撤销后项目会重新构建。您最新的工作会在撤销前被检查点保存，以便重做可以恢复它。每次撤销和重做都会记录在聊天中，以便 AI 保持了解。

<Warning>
  构建运行时撤销和重做不可用。全新项目在第二次更改之前没有可撤销的内容。
</Warning>

<Warning>
  在处于历史记录内部时（撤销后）进行的手动代码编辑器编辑不会被捕获。下一次撤销、重做或恢复会无警告地丢弃它们。请先返回到最新状态，或让 AI 进行更改。
</Warning>

<Info>
  对于 Shopify 项目，**撤销**、**重做**和**修订历史**按钮是隐藏的。只显示**下载主题 (.zip)**。键盘快捷键在 Shopify 项目中仍然有效。
</Info>

## 修订历史

点击**时钟图标**打开修订历史。每次 AI 请求、样式编辑和设计更改前都会捕获检查点。Webza 保留最近的 20 个检查点。

列表显示标签、时间戳和文件数量。当前版本有**当前**徽章。点击任何版本上的**恢复**即可跳转到该版本。

恢复首先会检查点保存您当前的状态，因此恢复是可逆的。每次恢复都会触发重新构建。修订历史仅适用于网站和 WordPress 主题。

<Note>
  发布快照与修订历史是分开的。详细信息请参阅[发布](/zh/publish)页面。
</Note>

## WordPress Playground 预览

WordPress 主题项目在 WordPress Playground 内预览。Playground 有自己的重新加载控制，因此自动预览重新加载行为在那里工作方式不同。
