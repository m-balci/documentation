**自定义域名**让访客可以通过您自己的地址（例如 `goldencrust.com`）访问您的 Webza 网站，而不是默认的 `webza.ai` 子域名（例如 `golden-crust.webza.ai`）。Webza 不出售域名：您可以从任何域名提供商（注册商）购买域名，然后将其连接到您的项目。本页面将引导您完成域名的连接、验证和故障排除。

自定义域名可以提升您网站的：

- **品牌识别度**：网站看起来更专业、更可信。
- **搜索可见性**：您的内容在您控制的域名下建立权威性。
- **易记性**：简短、品牌化的地址更容易分享和记住。

<Info>
  自定义域名在 **Plus** 和 **Premium** 套餐中可用。免费套餐不提供。请参见[套餐](/zh/subscription-plans)以比较各套餐。
</Info>

## 开始之前

请确保您已准备好以下内容：

- **您拥有的域名。** 如果您还没有，可以从域名提供商（如 GoDaddy、Namecheap 或 Cloudflare）购买。
- **访问您域名的 DNS 设置权限。** 您需要在域名提供商处添加 DNS 记录以验证所有权。如果其他人管理您的域名（例如 IT 团队或代理商），请向他们请求访问权限或发送记录信息。
- **已发布的项目。** 您可以随时连接域名，但域名只有在您[发布项目](/zh/publish)后才会显示您的网站。

## 连接您的域名

<Steps>
  <Step title="打开项目的域名设置">
    打开您要连接的项目，然后前往**设置 → 域名 → 自定义域名**。
  </Step>
  <Step title="输入您的域名">
    输入您要使用的域名，例如 `goldencrust.com`，然后继续。只输入域名名称，不要带 `https://` 或尾部斜杠。
  </Step>
  <Step title="查看验证页面">
    Webza 会显示一个验证页面，列出您需要添加的 DNS 记录。请保持此页面打开：下一步您需要从这里将每条记录复制到您的域名提供商处。
  </Step>
  <Step title="在域名提供商处添加 DNS 记录">
    在新标签页中登录您的域名提供商，并打开您域名的 DNS 设置（有时称为 **DNS 管理**、**DNS 区域**或**高级 DNS**）。对于 Webza 验证页面上的每条记录：

    1. 选择**添加记录**。
    2. 选择与 Webza 显示的相同的记录**类型**。
    3. 完全按照显示的内容复制**主机**（也称为**名称**）和**值**（也称为**指向**、**目标**或**内容**）。
    4. 保存记录。

    <Tip>
      使用复制按钮复制值，而不是手动输入。单个字符缺失是验证失败最常见的原因。
    </Tip>
  </Step>
  <Step title="验证您的域名">
    返回 Webza 并在验证页面上启动验证。Webza 会检查您的 DNS 记录并确认您拥有该域名。

    验证成功后，您的域名即已连接，您已发布的网站将开始通过自定义域名加载。
  </Step>
</Steps>

<Note>
  DNS 更改可能需要几分钟到 48 小时才能在互联网上传播（这称为 **DNS 传播**）。如果验证没有立即成功，请等待一段时间再重试。您不需要移除并重新添加域名。
</Note>

## 根域名、www 和子域名

- **根域名**（`goldencrust.com`）：添加验证页面上显示的记录。
- **www 域名**（`www.goldencrust.com`）：Webza 还会要求根域名的记录，因为安全证书覆盖两者。只有两条记录都就位后，验证才能通过。
- **子域名**（`shop.goldencrust.com`）：您只需要该子域名的记录。Webza 会为该名称颁发证书。

## 不同提供商的主机名工作方式

域名提供商对主机字段的标注方式不同。当 Webza 显示根域名的记录时（例如 `goldencrust.com`），您的提供商可能期望主机字段中出现以下之一：

- `@`
- 空字段
- 您的完整域名，例如 `goldencrust.com`

部分提供商会自动在主机末尾添加您的域名。如果记录的主机是 `www`，保存后提供商显示 `www.goldencrust.com`，这是正确的。如果显示 `www.goldencrust.com.goldencrust.com`，请删除重复部分并重新保存。

## 域名连接后

- **分享您的新地址。** 在任何地方使用您的自定义域名：名片、社交资料和电子邮件签名。
- **保持 DNS 记录不变。** 如果您删除或更改添加的记录，您的域名将停止显示网站。
- **发布以更新网站。** 您的在线网站是一个快照。您在编辑器中所做的更改只有在再次发布后才会出现在自定义域名上。详情请参见[发布](/zh/publish)。

## 故障排除

<AccordionGroup>
  <Accordion title="验证一直失败">
    在您的域名提供商处检查以下常见原因：

    - 记录**类型**与 Webza 显示的完全一致。
    - **值**已完整复制，没有多余空格或缺失字符。
    - **主机**符合您提供商的格式。请参见[不同提供商的主机名工作方式](#不同提供商的主机名工作方式)。
    - 您已保存记录。部分提供商需要单独的**保存**或**应用更改**步骤。

    如果一切看起来正确，请等待 DNS 传播完成并再次验证。
  </Accordion>

  <Accordion title="我的域名仍然显示旧网站">
    您的域名提供商可能仍有来自您之前网站或托管服务商的记录。删除指向其他位置的相同主机的旧记录，只保留 Webza 要求的记录。然后等待 DNS 传播完成。
  </Accordion>

  <Accordion title="我的域名显示空白页或错误">
    请确保您的项目已发布。已连接的域名只有在您[发布](/zh/publish)后才会显示您的网站。如果您最近刚发布，请等待几分钟并刷新页面。
  </Accordion>

  <Accordion title="我使用 Cloudflare，网站无法加载">
    如果您的 DNS 在 Cloudflare 中管理，请将您为 Webza 添加的记录设置为 **DNS only**（灰色云）而不是 **Proxied**（橙色云），然后再次验证。
  </Accordion>

  <Accordion title="我在提供商处找不到 DNS 设置">
    在提供商的帮助中心搜索"管理 DNS 记录"或"添加 DNS 记录"。如果您的域名使用其他服务的名称服务器（例如 Cloudflare），请在该服务而不是购买域名的注册商处添加记录。
  </Accordion>
</AccordionGroup>

## 常见问题

<AccordionGroup>
  <Accordion title="我可以通过 Webza 购买域名吗？">
    不可以。Webza 不出售域名。从任何域名提供商购买域名，然后使用本页面的步骤将其连接到您的项目。
  </Accordion>

  <Accordion title="连接自定义域名后，我的 webza.ai 子域名会保留吗？">
    您的项目会保留其 `webza.ai` 子域名。域名连接后，访客可以通过您的自定义域名访问您的网站。
  </Accordion>

  <Accordion title="我可以在发布项目之前连接域名吗？">
    可以。您可以随时连接和验证域名，但它只有在您发布项目后才会显示您的网站。
  </Accordion>

  <Accordion title="我需要将域名转移到 Webza 吗？">
    不需要。您的域名保留在当前提供商处注册。您只需在那里添加 DNS 记录，将域名指向您的 Webza 网站即可。您继续向您的提供商支付域名费用并续费。
  </Accordion>

  <Accordion title="DNS、DNS 记录和传播是什么意思？">
    - **DNS** 是告诉浏览器在哪里找到域名对应的网站的系统。
    - **DNS 记录** 是您域名设置中的条目，用于将域名指向某个服务或证明您拥有它。
    - **传播** 是 DNS 更改在互联网上更新所需的时间，通常从几分钟到几小时，最长可达 48 小时。
  </Accordion>
</AccordionGroup>
