Кодовый редактор — это встроенный редактор Monaco, который позволяет просматривать и редактировать файлы проекта напрямую. Он предлагает подсветку синтаксиса, поиск и замену, сохранение по требованию и индикатор несохраненных изменений, чтобы вы всегда знали, что ожидает сохранения.

## Поддерживаемые языки

Редактор подсвечивает синтаксис для наиболее распространенных типов веб-файлов:

- JavaScript и TypeScript (`.js`, `.ts`, `.tsx`)
- CSS и HTML
- JSON и Markdown

## Поиск и замена

Нажмите <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>F</kbd>, чтобы открыть окно поиска внутри редактора. Вы можете искать в текущем файле и заменять совпадения по одному или все сразу.

## Сохраните изменения

Нажмите <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>S</kbd>, чтобы сохранить текущий файл. Точка или индикатор несохраненных изменений появляется рядом с именем файла до тех пор, пока вы не сохраните. Живой предпросмотр обновляется после сохранения.

Нельзя сохранить файл, пока ИИ выполняет сборку. Редактор показывает сообщение с объяснением причины, а ваш несохраненный текст остается в редакторе, чтобы вы могли сохранить его после завершения сборки.

## Файлы только для чтения

Небольшой набор системных файлов доступен только для чтения. Они управляются шаблоном и системой сборки, и плохая правка может привести к невозможности пересборки проекта. Когда вы выбираете один из этих файлов, редактор показывает бейдж **Только для чтения** с замком и скрывает кнопку **Сохранить**.

<AccordionGroup>
  <Accordion title="Файлы только для чтения на уровне корня">
    `index.html`, `package.json`, `package-lock.json`, `vite.config.ts`, `tsconfig.json`, `tsconfig.node.json`, `components.json`, `tailwind.config.ts`, `tailwind.config.js`, `postcss.config.js`, `postcss.config.cjs`
  </Accordion>

  <Accordion title="Исходные файлы только для чтения">
    `src/main.tsx`, `src/index.css`, `src/vite-env.d.ts`
  </Accordion>

  <Accordion title="Системные файлы только для чтения">
    `memory.json`, `design-intelligence.json`, `KNOWLEDGE.md`, `template.json`
  </Accordion>
</AccordionGroup>

Нет настройки для разблокировки этих файлов. `index.html` — это только оболочка, загружающая приложение. Каждая видимая страница, заголовок, подвал и ссылка находятся под `src/`, и все там редактируемо, за исключением `main.tsx`, `index.css` и `vite-env.d.ts`.

## Сниппеты аналитики и отслеживания

Если вам нужно добавить Google Tag Manager, Google tag или Meta Pixel, используйте карточку **Аналитика** в разделе **Настройки → Общие** вместо прямого редактирования разметки в head. См. раздел [Настройки](/ru/settings).

## Важные предупреждения

<Warning>
  Ручные правки, сделанные, пока вы находитесь внутри истории версий (после отмены), отбрасываются следующей операцией **Undo** или **Restore**. Подробности об истории версий см. в разделе [Предпросмотр](/ru/preview).
</Warning>

<Info>
  Сгенерированные ИИ изображения хранятся в `public/images/generated/`. Вы можете ссылаться на них в коде, но не перемещайте и не переименовывайте их вне чата, иначе ИИ может потерять их из виду.
</Info>
