Проектный редактор — это рабочая область, в которую вы попадаете после нажатия **Начать** на карточке проекта на панели управления. Он объединяет чат, предпросмотр, код и настройки в одном месте, чтобы вы могли создавать и дорабатывать свой сайт, не переключая вкладки.

Вы можете свернуть панель чата, чтобы предпросмотр занял всю ширину. Это полезно, когда вы сосредоточены на деталях дизайна и не нуждаетесь в помощи ИИ.

## Панель инструментов

Верхняя панель инструментов предоставляет быстрые действия для текущего проекта:

- **Опубликовать**: Открывает процесс публикации, чтобы выложить ваш сайт в интернет. См. раздел [Публикация](/ru/publish).
- **Пересобрать**: Пересобирает проект из последнего кода. Используйте это, если предпросмотр выглядит рассинхронизированным.
- **Повторить обзор**: Кнопка с круговой стрелкой рядом с **Пересобрать** воспроизводит обзорный тур по редактору.
- **Экспорт**: Если ваш тариф включает экспорт кода (Plus или Premium), эта кнопка скачивает полный исходный код в виде ZIP-файла, готового к развертыванию на Vercel или размещению где угодно.
- **Скачать тему**: Для проектов с темами возвращает устанавливаемую блочную тему WordPress или тему Shopify Online Store 2.0 в виде ZIP-файла вместо полного экспорта исходного кода.

## Экспорт проекта

Если ваш тариф поддерживает это, вы можете скачать свой проект и разместить его вне Webza.

<Steps>
  <Step title="Откройте редактор">
    Нажмите **Начать** на карточке проекта на панели управления.
  </Step>
  <Step title="Нажмите Экспорт">
    На панели инструментов нажмите **Экспорт** (или **Скачать тему** для проектов с темами).
  </Step>
  <Step title="Скачайте ZIP">
    Файл скачивается на ваш компьютер. Распакуйте его и следуйте README внутри для локальной разработки или развертывания на Vercel.
  </Step>
</Steps>

## Сочетания клавиш

| Действие | Сочетание клавиш |
| --- | --- |
| Отменить | <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>Z</kbd> |
| Повторить | <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> или <kbd>Ctrl</kbd> + <kbd>Y</kbd> |
| Поиск в кодовом редакторе | <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>F</kbd> |
| Сохранить в кодовом редакторе | <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>S</kbd> |
| Отправить сообщение в чат | <kbd>Enter</kbd> |
