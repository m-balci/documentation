---
title: "Опубликовать"
description: "Узнайте, как опубликовать проект Webza, управлять снимками и контролировать видимость сайта."
---

Публикация делает ваш проект доступным в интернете. Одного создания сайта недостаточно, чтобы разместить его в сети. Нужно нажать **Опубликовать**, чтобы выполнить развертывание.

## Опубликовать проект

<Steps>
  <Step title="Откройте диалог публикации">
    На панели инструментов редактора нажмите **Опубликовать**.
  </Step>
  <Step title="Выберите поддомен">
    Введите желаемое имя для адреса `*.webza.ai`. Webza проверяет доступность по мере ввода и предлагает короткое имя на основе названия проекта. Некоторые имена зарезервированы и будут отклонены.
  </Step>
  <Step title="Настройте видимость">
    Выберите **Публичный**, чтобы любой, у кого есть ссылка, мог просматривать сайт, или **Приватный**, чтобы только вы, вошедшие в Webza в этом браузере, могли его видеть. Всем остальным доступ будет запрещен.

    <Note>
      Приватная видимость доступна в рамках определенных тарифов. Если ваш тариф не включает эту функцию, опция будет заблокирована с надписью "Обновите тариф, чтобы разблокировать приватную видимость."

      {/* TODO: confirm which Webza plans include private visibility */}
    </Note>
  </Step>
  <Step title="Подтвердите и опубликуйте">
    Нажмите **Опубликовать**. Webza сначала создаст снимок, а затем развернет сайт.
  </Step>
</Steps>

После публикации кнопка на панели инструментов изменится на **Published**. Нажатие открывает окно публикации, в котором вы можете:

- **Visit**: открыть опубликованный сайт в новой вкладке. Для приватных сайтов, в том числе на пользовательских доменах, используйте **Visit**, чтобы открыть сайт от имени владельца.
- **Copy link**: скопировать адрес сайта.
- **Unpublish**: снять сайт с публикации.
- Изменить поддомен, видимость и другие настройки.

## Перепубликация после изменений

Ваш живой сайт не обновляется автоматически при создании. Перепубликуйте сайт, когда хотите, чтобы последние изменения стали доступны в сети. Каждая перепубликация создает новый снимок.

## Снимки публикации

Каждая публикация создает **Снимок перед публикацией**, который отображается в разделе **Предыдущие версии** в диалоге публикации. Хранятся только пять последних снимков для каждого проекта.

Откат восстанавливает опубликованный результат предпросмотра, а не исходный код проекта. При следующем создании сайт все равно будет сгенерирован из текущего исходного кода. Чтобы отменить фактические изменения кода, используйте **Отменить** или **История версий**. Подробности см. в разделе [Предпросмотр](/ru/preview).

## Пользовательские домены

После публикации проекта вы можете направить на него свой собственный домен. Тарифы Plus включают 1 пользовательский домен, Premium включают 3. Шаги по настройке см. в разделе [Домены](/ru/custom-domains).

Проект должен оставаться опубликованным. Снятие с публикации также отключит пользовательский домен.

## Изображение для публикации

Перед публикацией сайта в социальных сетях задайте изображение для публикации в разделе **Настройки** -> **Основные**. Подробности см. в разделе [Настройки](/ru/settings).

## Темы WordPress и Shopify

Проекты тем WordPress и Shopify не размещаются на Webza. Вы экспортируете файл темы `.zip` и устанавливаете его на свой сайт WordPress или магазин Shopify. Для тем WordPress вкладка **Домены** никогда не отображается.

## Снятие с публикации

Чтобы отключить сайт, откройте окно публикации и нажмите **Unpublish**. Это удалит живой сайт и любой связанный пользовательский домен из интернета.
