Тарифы Plus и Premium включают доступ к API. Персональный API, это REST API только для чтения, который позволяет вам программно получать данные вашего аккаунта Webza. Вы не можете создавать проекты, запускать сборки или менять биллинг через API.

## Создание API-ключа

Откройте страницу **API-ключи** из боковой панели.

<Steps>
  <Step title="Сгенерируйте ключ">
    Нажмите, чтобы создать новый ключ. Каждый ключ показывается только один раз при создании, так что скопируйте его сразу и храните в безопасности.
  </Step>
  <Step title="Задайте срок действия (по желанию)">
    Выберите срок действия 30, 90 или 365 дней, или оставьте без срока действия.
  </Step>
  <Step title="Отзовите при необходимости">
    Вы можете отозвать любой ключ в любое время. У вас может быть до 10 ключей на аккаунт.
  </Step>
</Steps>

<Warning>
  Храните ваши ключи в секрете. Они предоставляют доступ к данным вашего аккаунта, пока не будут отозваны или не истечет их срок действия.
</Warning>

## Аутентификация

Отправляйте ваш ключ как Bearer token в заголовке `Authorization`:

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" https://webza.ai/api/v1/...
```

## Эндпоинты и документация

API открывает ресурсы под `/api/v1` для вашего аккаунта, кредитов, подписки, проектов, уведомлений и счетов.

Откройте страницу **API-документация** из боковой панели, чтобы увидеть каждый эндпоинт. Документация включает интерактивный тестер и примеры для копирования в curl, JavaScript, PHP и Python.
