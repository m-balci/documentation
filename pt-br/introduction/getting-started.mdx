Crie seu primeiro site com o Webza e coloque-o no ar em cerca de dez minutos. Não há nada para instalar e nada para configurar: você descreve o que deseja, o Webza projeta e constrói, e você publica em um endereço real que pode compartilhar. Neste guia, você cria um site para a **Golden Crust**, uma padaria fictícia do bairro, com uma página inicial, um cardápio com preços e um formulário de pedido. Substitua pela sua própria ideia em qualquer etapa; o processo permanece o mesmo.

Construir com o Webza usa [créditos](/pt-br/credits-and-usage), e o plano gratuito inclui uma concessão única de 2 milhões de créditos de IA. Veja [Planos de assinatura](/pt-br/subscription-plans) para o que cada plano inclui.

<Steps>
  <Step title="Criar sua conta">
    [Cadastre-se gratuitamente](https://webza.ai/register?utm_source=webza_docs&utm_medium=content) com e-mail, Google ou GitHub. O Webza abre seu painel, pronto para criar. Para login, redefinição de senha e configurações da conta, veja [Criar uma conta](/pt-br/introduction/create-an-account).
  </Step>
  <Step title="Descrever seu site">
    A caixa de prompt no [painel](/pt-br/introduction/dashboard-overview) é onde todo projeto começa. Descreva o site que deseja em linguagem simples.

    Experimente este prompt ou adapte-o à sua própria ideia:

    ```text Prompt wrap
    Build a website for Golden Crust, a neighborhood bakery. Include a warm hero section with a headline and an "Order online" button, a menu page with sourdough, croissants, and cinnamon rolls with prices, an About section with the bakery's story, and an order form where visitors enter their name, the items they want, and a pickup time. Use realistic sample content. Cozy, modern design. Works well on mobile.
    ```

    <Tip>
      Seja específico sobre páginas, seções e a sensação que deseja. Quanto mais contexto você der no primeiro prompt, mais próxima a primeira versão estará do que você imaginou.
    </Tip>

    <Accordion title="Usar sua própria ideia">
      Adapte um destes exemplos, ou escreva seu próprio prompt do zero. As etapas deste guia permanecem as mesmas.

      ```text Portfolio wrap
      Build a portfolio website for a freelance photographer: a full-width gallery, an About page, a services and pricing section, and a contact form. Minimal, elegant design.
      ```

      ```text Local business wrap
      Build a website for a dental clinic: a homepage with services, a team section with photos, opening hours, a location section, and an appointment request form. Clean, trustworthy design.
      ```

      ```text Landing page wrap
      Build a landing page for a mobile app that helps people track their daily water intake: a hero with a download button, a features section, testimonials, and an FAQ. Fresh, bright design.
      ```
    </Accordion>
  </Step>
  <Step title="Ver a primeira versão aparecer">
    O Webza cria seu projeto e começa a construir. A primeira versão leva alguns minutos.

    Quando estiver pronta, você trabalha no [editor](/pt-br/editor): o [chat do projeto](/pt-br/project-chat), onde conversa com o Webza, fica ao lado do [preview](/pt-br/preview), onde seu site roda ao vivo. Clique pelo preview, abra o menu e role pelas seções.
  </Step>
  <Step title="Fazer uma alteração">
    Peça uma mudança de cada vez no chat do projeto e verifique o preview após cada uma. Por exemplo:

    ```text Prompt wrap
    Add a "Today's specials" section above the menu that highlights two items with a short description and price.
    ```

    Se o site funciona, mas não tem a aparência que você imaginou, diga isso em palavras simples. Este é um prompt perfeitamente válido:

    ```text Prompt wrap
    Make the whole site feel warmer and less corporate.
    ```

    Você também pode editar visualmente no [editor](/pt-br/editor), ou abrir o [editor de código](/pt-br/code-editor) para controle total sobre os arquivos do seu site. Suas alterações permanecem privadas até você [publicar](/pt-br/publish).
  </Step>
  <Step title="Verificar se tudo funciona">
    Antes de publicar, dedique alguns momentos para testar seu site:

    - Clique em todos os botões e links.
    - Preencha o formulário de pedido para garantir que todos os campos funcionam.
    - Verifique como o site fica em um celular. A maioria dos visitantes abrirá seu link no mobile.

    Se algo estiver errado, diga ao Webza exatamente o que está errado e onde:

    ```text Prompt wrap
    On the menu page, the "Order online" button does nothing. It should scroll to the order form.
    ```
  </Step>
  <Step title="Publicar">
    Selecione **Publicar** no editor, junto com as outras ações do projeto. Após uma curta implantação, seu site está no ar em um subdomínio gratuito do `webza.ai` (por exemplo, `golden-crust.webza.ai`), pronto para compartilhar. Veja [Publicar seu site](/pt-br/publish) para detalhes, e [Domínios personalizados](/pt-br/custom-domains) para usar seu próprio domínio.

    <Note>
      **Seu site no ar é um snapshot.** Alterações que você faz após a publicação aparecem no preview imediatamente, mas o site no ar só é atualizado quando você publica novamente.
    </Note>
  </Step>
</Steps>

Esse é todo o ciclo: descreva, refine, publique. Todo site que você cria com o Webza, por mais ambicioso que seja, é este ciclo repetido.
