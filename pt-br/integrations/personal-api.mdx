Os planos Plus e Premium incluem acesso à API. A API Pessoal é uma API REST somente leitura que permite acessar os dados da sua conta Webza programaticamente. Você não pode criar projetos, disparar builds ou alterar faturamento pela API.

## Criar uma chave de API

Abra a página **API Keys** na barra lateral.

<Steps>
  <Step title="Gerar uma chave">
    Clique para criar uma nova chave. Cada chave é mostrada apenas uma vez na criação, então copie-a imediatamente e guarde-a com segurança.
  </Step>
  <Step title="Definir expiração (opcional)">
    Escolha uma expiração de 30, 90 ou 365 dias, ou deixe sem expiração.
  </Step>
  <Step title="Revogar quando necessário">
    Você pode revogar qualquer chave a qualquer momento. Você pode ter até 10 chaves por conta.
  </Step>
</Steps>

<Warning>
  Mantenha suas chaves em segredo. Elas concedem acesso aos dados da sua conta até serem revogadas ou expirarem.
</Warning>

## Autenticar

Envie sua chave como um token Bearer no cabeçalho `Authorization`:

```bash
curl -H "Authorization: Bearer SUA_CHAVE_DE_API" https://webza.ai/api/v1/...
```

## Endpoints e documentação

A API expõe recursos sob `/api/v1` para sua conta, créditos, assinatura, projetos, notificações e faturas.

Abra a página **API Docs** na barra lateral para ver cada endpoint. A documentação inclui um testador interativo e amostras copiáveis em curl, JavaScript, PHP e Python.
