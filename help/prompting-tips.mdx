Webza builds websites from your instructions. The clearer your prompts, the closer the first result matches what you want. These tips help you save time and credits.

## Be specific

Include details about features, design preferences, and requirements. Descriptive prompts produce more accurate builds than vague ones.

**Vague:**

> Make a landing page for my bakery.

**Specific:**

> Build a one-page bakery landing page with a hero section, three-column menu cards, an order form, and a footer with opening hours. Use warm brown and cream colors. Make the hero headline "Fresh Bread Daily".

## Iterate in steps

Start with the basics and add features incrementally. Large, all-at-once requests are harder to refine than small, focused ones.

1. Build the homepage layout.
2. Add a contact form.
3. Adjust the color palette.
4. Add animations.

Each step gives the AI a clear target and lets you review progress before moving on.

## Reference examples

Mention websites or designs you like. Attach screenshots or mockups so the AI can see the style you want.

<Tip>
  Vision models can see JPG, PNG, WebP, and GIF images. You can attach up to 4 images per message.
</Tip>

Use **@** to mention uploaded files in your prompt.

## Ask for explanations

The AI can explain its code and design decisions. Ask "Why did you choose this layout?" or "Explain how the form validation works" to learn and to decide if you want changes.

## Use templates and design systems

Save time by starting from a [design system](/design-systems) or a [template](/templates). This sets consistent colors, typography, and components before you add custom content.

## Use project Knowledge for durable rules

Open **Settings** and go to **Knowledge** to store rules that apply to every build. This is ideal for brand voice, default language, or libraries to avoid. Knowledge is limited to 500 characters and is paid for on every build, so keep it focused on rules you need repeatedly.

Put one-off requests in the project chat instead.

## Save credits with batch edits

When you edit text or images in the inspector, batch your changes and press **Save All** once. Each **Save All** runs a build and spends credits, so grouping edits reduces total cost.

## Answer clarifying questions for free

When the AI asks a clarifying question via a question card, answering does not cost credits while you are waiting. Use this to refine the direction before the next build starts.

## Keep your first prompt focused

Your first prompt can be up to 10,000 characters. Use the space for structure and goals rather than every minor detail. You can refine specifics in follow-up messages.

## Fix failed runs for free

If a run fails due to the AI or platform, use the **Fix** option in [project chat](/project-chat) to retry at no extra cost.
